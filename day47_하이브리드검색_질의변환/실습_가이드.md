# 하이브리드 검색·질의 변환 실습 가이드

교안 01 → 교안 02 → 교안 03 → LV1 → LV2 순서로 진행합니다. 과제는 앞 문항에서 만든 변수를 이어 쓰므로 1번부터 차례로 풉니다.

## 0. 준비

- [ ] 저장소 최상위에서 `uv sync`로 환경을 만듭니다. 패키지 버전은 최상위 `pyproject.toml`에 있습니다.

```bash
uv sync
```

- [ ] VS Code에서 노트북을 열고 `.venv`의 Python 3 (ipykernel) 커널을 선택합니다.
- [ ] `.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY`를 넣습니다. 교안 03에는 `TYPESAFE_API_KEY`도 넣습니다. LV1은 임베딩만 요청하고 GPT는 호출하지 않습니다.

## 1. 진행 순서

- [ ] [교안 01](교안_01_하이브리드_검색.ipynb): BM25와 Dense를 만들고 가중 RRF로 합친 뒤, 같은 상위 3개에서 Recall을 비교합니다. PDF 따라하기는 앞 절에서 만든 검색기를 이어 씁니다.
- [ ] [교안 02](교안_02_질의_변환.ipynb): Self-Query로 조건을 뽑아 두 검색에 함께 적용하고, HyDE·Multi-Query·Step-back·Decomposition 각각에서 하이브리드 검색 후 원문으로 답변합니다. 변환 전후의 후보 Recall과 문서 수도 비교합니다.
- [ ] [교안 03](교안_03_Jev_출력과_쿼리분기_RAG.ipynb): Jev 판단과 실제 RAG 분기. 따라하기 없이 실행 가능한 시연입니다.
  - [ ] 1절: Jev의 역할·입력·출력과 SDK를 준비합니다.
  - [ ] 2절: Noul로 참일 확률을 판단하고 코드의 기준으로 분기합니다.
  - [ ] 3절: Choice의 선택·확률·confidence를 읽습니다.
  - [ ] 4절: Score의 수준·확률 가중평균을 확인합니다.
  - [ ] 5절: 독립 질문 세 개를 한 요청에 묶습니다.
  - [ ] 6절: `query_transforms.py` 가져오기·검색 준비 → Jev 선택 → 모듈의 `retrieve` 호출 → 원문 답변 → 인용 대조 → 범위 밖 질문 확인.
- [ ] [LV1 기초](과제_LV1_기초.ipynb) 8문항: 교안 01 내용. 한국어 백과로 토큰화·BM25·Dense·`EnsembleRetriever`·가중치 비교와 RRF·BM25 원리 서술.
- [ ] [LV2 응용](과제_LV2_응용.ipynb) 8문항: 교안 02 내용. 릴리스 노트로 Self-Query·같은 조건 하이브리드·HyDE·Multi-Query·Step-back·Decomposition·근거 답변, 변환 선택과 결과 해석 서술.

교안 01·02와 과제의 완성 코드는 수업이 끝난 뒤 강사가 공유합니다. 교안 03은 완성 시연이며, 질의 변환·검색 구현은 같은 폴더의 [query_transforms.py](query_transforms.py)를 가져와 사용합니다.

## 막혔을 때

- `FileNotFoundError`: 노트북이 있는 폴더에서 실행했는지 확인합니다.
- import 에러: 패키지를 설치한 `.venv`와 노트북 커널이 같은지 확인합니다. `query_transforms`를 찾지 못하면 `query_transforms.py`가 교안 03과 같은 폴더에 있는지 확인합니다.
- 인증·모델 접근 에러: `.env`의 `OPENAI_API_KEY`와, 필요하면 `OPENAI_CHAT_MODEL`을 확인합니다.
- Jev 인증·모델 오류: `.env`의 `TYPESAFE_API_KEY`와 `TYPESAFE_MODEL`을 확인합니다. 기본 모델은 `jev-1.13.0`입니다.
- 필터 결과가 0건: 출력된 조건과 데이터의 `metadata` 값을 비교합니다. 조건을 지우지 말고 질문을 더 분명하게 씁니다.
- 교안 따라하기에서 추출한 조건이 원질문과 다름: 분류 이름과 비교 표현(이상·초과)을 질문에 분명히 적고 다시 추출합니다. 다시 추출할 때마다 GPT 요청이 한 번 늘어납니다. 과제는 추출 결과를 그대로 씁니다.

## 완주 기준

- [ ] Noul·Choice·Score를 구분하고, 선택된 변환이 실제 실행됐는지 검색 입력과 원문으로 확인할 수 있습니다.
- [ ] BM25의 희귀도·빈도 포화·길이 보정을 설명하고 `k1`·`b`와 반환 개수 `k`를 구분할 수 있습니다.
- [ ] RRF의 `c`와 `k`, 가중치의 뜻을 구분하고 두 검색 결과를 원문 ID로 합칠 수 있습니다.
- [ ] 같은 조건을 두 검색에 적용하고, 질의 변환의 검색 입력과 답변 근거를 구분할 수 있습니다.
