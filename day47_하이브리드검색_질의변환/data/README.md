# 데이터 안내

이번 자료는 앞 단원(청킹 전략과 RAPTOR)의 실제 원문을 그대로 쓰고, 레코드 하나를 검색 단위 하나로 씁니다. 각 JSON 레코드의 `doc_id`는 노트북에서 `metadata.source_id`로 유지됩니다. `text`가 임베딩·BM25의 본문이며 `title`·`url`·분류는 메타데이터입니다.

| 파일 | 규모 | 성격과 추가 필터 |
|---|---:|---|
| `demo_docs.json` | 10권 | 수업용 가상 도서관 장서. 제목과 짧은 소개문이 본문이며 category·year도 가상 값입니다. |
| `practice_docs.json` | 44절 | 고용노동부 2024 유연근무 활용 매뉴얼. category는 수업용 분류, pdf_page는 실제 PDF 페이지입니다. |
| `lv1_docs.json` | 5개 | 한국어 백과 도입문. category(언어·데이터)는 수업용 분류입니다. |
| `lv2_docs.json` | 5개 | 과거 Neo4j 릴리스 노트. series·stage는 원래 제목의 버전에서 추출했습니다. |
| `lv3_docs.json` | 6개 | pandas 사용자 가이드 발췌. category는 수업용 분류입니다. 이번 과제에서는 쓰지 않으며, 다음 단원 자료가 이 파일을 가져갑니다. |
| `practice_questions.json` | 82문항 | 질문·참고 답안·대표 인용과 검색 평가용 정답 문서 목록. 교안 01은 일부 질문으로 비교합니다. |
| `sources.json` | 출처 목록 | 원본 파일, 문서 URL, 본문 SHA-256, 변환 규칙을 기록합니다. |

실제 문서의 `text`는 앞 단원과 같고 필터에 쓸 `metadata`만 더했습니다. 레코드가 이미 짧아 다시 나누지 않으므로, 교안 01은 앞 단원의 근거 구간 Recall 대신 **원문 ID Recall**을 씁니다.

## 실제 PDF

원본 [유연근무 활용 매뉴얼 PDF](originals/MOEL_flexible_work_manual_2024.pdf)는 167쪽입니다. [원문 게시 페이지](https://www.worklife.kr/website_renew/index/newsroom/press_releases_view.asp?GUID=B1C5B341-D745-40C5-9D6B-769F3D75E921)에서 제공된 앞 교안의 동일 파일을 사용합니다. 발췌는 40개 페이지의 44절이며, `pdf_page`는 뷰어의 1부터 시작하는 페이지 번호입니다. 본문의 인쇄 쪽수와 다릅니다.

분류는 PDF 장의 구성을 따라 ‘공통’, ‘시차출퇴근’, ‘선택근무’, ‘재택근무’로 작성했습니다. 질문에서 분류를 제한하면 그 안에서만 검색합니다. 모든 발췌는 2024년 문서의 고정된 학습 자료입니다.

## 과제 원문

백과·릴리스·사용자 가이드의 각 레코드에는 원문 URL과 앞 단원과 같은 수집 위치를 남겼습니다. 역사적 릴리스에 등장하는 옛 버전은 **검색할 문서의 내용**이며 이 실습에 설치할 패키지 버전은 저장소 최상위 `pyproject.toml`을 따릅니다. pandas 가이드에는 결측값·결합·변형·시각화·문자열·대용량 자료 처리에 대한 설명문을 사용합니다.

질의 변환 결과·검색 순위·LLM 답변을 데이터에 미리 넣지 않았습니다. 노트북은 실제 모델과 검색기를 사용하며 새 결과는 `output/`에 저장합니다.

## 검색 평가용 골드셋

- `evidence`: 참고 답안을 뒷받침하는 대표 인용과 원문 위치입니다.
- `relevant_doc_ids`: 질문의 전체 또는 일부 답을 직접 뒷받침하는 정답 문서 ID입니다. 같은 답의 대체 근거도 포함하며, 주제나 단어만 겹치는 문서는 제외합니다. Recall의 분모는 이 목록의 서로 다른 ID 수입니다.
- q1·q7·q32·q34·q61의 빠진 관련 문서를 보완했습니다. q32는 조사와 평가 준비를 모두 묻도록 질문을 명확히 했습니다.
- 관련 문서가 여러 개라도 답변에는 그중 일부만으로 충분할 수 있습니다. 문서 Recall은 답변 완성도를 측정하지 않습니다.
