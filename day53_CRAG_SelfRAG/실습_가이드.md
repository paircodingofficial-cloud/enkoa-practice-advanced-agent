## 오류와 예상 밖 결과 확인

- import 오류: README의 패키지와 선택한 Jupyter 커널을 확인합니다.
- 인증 오류: 키를 화면에 출력하지 말고 .env의 변수 이름을 확인합니다. 기존 환경에 등록된 값이 있으면 그 값을 우선 사용합니다.
- 검색 실패: 검색어와 원질문을 비교하고 선택된 문서 본문을 읽습니다.
- 판정 불일치: 질문·문서·초안·검토 의견을 나란히 보며 원문과 대조합니다.
- 그래프 반복: 재작성·검토 횟수가 증가하는 노드와 종료 분기 순서를 확인합니다.
- 정답 비교: 강사가 공유한 대응 노트북을 읽습니다. 모델의 문장까지 같을 필요는 없습니다.
