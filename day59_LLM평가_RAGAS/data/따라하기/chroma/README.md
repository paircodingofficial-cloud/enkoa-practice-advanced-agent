# 함께 따라하기 지원 서비스 검색 DB

문서 적재와 임베딩을 마친 배포용 Chroma DB입니다. **이 폴더 전체를 그대로 열어** 사용하세요. `chroma.sqlite3`와 하위 인덱스 폴더가 모두 필요합니다.

- 컬렉션: `day59_support`
- 저장 문서: 33개 (행정안전부 「대한민국 공공서비스(혜택) 정보」 중 출산·육아 지원 서비스, 서비스 하나가 레코드 하나)
- 임베딩: **`text-embedding-3-large`, 768차원**
- 거리: cosine
- 메타데이터: `source_id`(= 문서 ID), `title`, `agency`, `updated`, `url`
- 제작 환경: `chromadb==1.5.9`, `langchain-chroma==1.1.0`
- 출처: 행정안전부, 대한민국 공공서비스(혜택) 정보, 공공데이터포털(data.go.kr), 공공누리(출처표시)

질문도 같은 모델·차원으로 임베딩합니다.
