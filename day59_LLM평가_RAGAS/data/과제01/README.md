# 과제 01 데이터: 의약품 상담 도우미의 답변 기록

과제 01(`과제_01_의약품_상담_답변_품질_평가.ipynb`)이 읽는 자료입니다. 약국 체인 의약품 상담 도우미라는 수업용 가정이지만, 검색 문서와 정답 답변의 근거는 식품의약품안전처가 공개한 실제 안내문입니다. 의학적 조언이 아니며, 실제 복용은 의사·약사와 상의해야 합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `golden_set.json` | 골든셋 질문 6개. 질문마다 정답 답변(`reference`) |
| `rag_records.json` | 미리 저장한 RAG 실행 기록 12건(질문 6개 x 프롬프트 `v1`·`v2`). 답변(`response`), 검색 문서 본문(`retrieved_contexts`)과 ID(`context_doc_ids`) |
| `sources.json` | 원문 출처, 쓴 안내문의 sha256, 정답 답변 주장마다의 근거 문장과 그 문장이 있는 안내문 ID |

## 골든셋 (`golden_set.json`)

```json
{"question_id": "g1", "drug": "신일비사코딜정", "user_input": "변비가 심해서 …", "reference": "성인은 1일 1회 2정(10 mg)을 …"}
```

- 질문은 약국에서 실제로 받을 법한 복용법·병용·연령 질문입니다.
- 정답 답변은 사람이 그 제품의 안내문을 읽고 주장 2~3개를 골라 풀어 썼습니다(모델로 만들지 않음). 의약품 이름·용량·나이는 원문 그대로이고, 원문에 없는 사실이나 계산은 넣지 않았습니다.
- 주장마다 원문 근거 문장을 `sources.json`의 `golden_claims`에 적어 두었고, 빌드 스크립트가 근거 문장이 그 안내문 본문에 그대로 있는지 검사합니다.

## 실행 기록 (`rag_records.json`)

```json
{"question_id": "g1", "version": "v1", "response": "…", "context_doc_ids": ["drug_197600483", "drug_199302061"], "retrieved_contexts": ["신일비사코딜정\n제조사: …", "…"]}
```

- 두 버전은 같은 검색기를 쓰고 답변 프롬프트만 다릅니다. 그래서 같은 질문의 두 기록은 검색 문서가 같습니다.
- 검색 문서는 질문마다 상위 2편이고, 1위는 질문한 제품의 안내문입니다. 본문은 day58 과제처럼 `title + "\n" + text`입니다.
- 답변은 RAG를 실행했다면 남았을 기록을 수업용으로 사람이 써서 넣었습니다.
- 실행 기록의 답변 일부에는 평가 연습을 위해 안내문과 다른 용량·근거 없는 조언을 일부러 넣었습니다. 복용 정보로 쓰지 마세요.

## 출처와 이용 조건

- 식품의약품안전처 의약품개요정보(e약은요), 공공데이터포털 <https://www.data.go.kr/data/15075057/openapi.do>.
- 공공누리 제1유형(출처표시). 안내문 본문은 `day58_RAG_아키텍처_설계/data/과제/docs.jsonl`에서 그대로 가져왔습니다. 수집 이후 안내문이 바뀌었을 수 있습니다.
