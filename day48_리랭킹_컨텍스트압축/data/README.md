# 데이터 안내

일반 실습은 **한글 가상 도서 51권의 소개·학습 내용**을 사용합니다. 책 제목과 소개는 수업을 위해 창작했으며 실제 출판물 정보가 아닙니다. 따라하기는 앞 단원의 실제 문서를, 과제는 **수업용 가상 사내 문서**(IT 헬프데스크 도움말·사내 규정)를 사용합니다.

## 문서와 근거

문서 레코드는 `doc_id`, `title`, `text`, `url`, `source`, `metadata`로 구성됩니다. `text`가 검색·리랭킹·압축 대상인 원문이며 `doc_id`는 노트북의 `metadata.source_id`로 이어집니다. 리랭킹과 압축 뒤에도 이 ID와 출처를 유지합니다. 질문의 `evidence`에는 필요한 원문의 `doc_id`가 있으며, 매뉴얼 질문에는 근거 문장과 원문 문자 구간도 포함됩니다.

가상 도서는 `source`를 `수업용 가상 도서`, `url`을 빈 문자열로 표시합니다. `metadata`에는 분야(`category`), 출간 연도(`year`), 난이도(`level`)가 있습니다. 각 소개는 대상 독자·학습 내용·다루지 않는 범위를 설명합니다. 에이전트 구축을 묻는 세 검색 질문마다 관련 도서 4권과 부분 관련 도서 3권을 두었습니다(book31~book51). 부분 관련 도서는 질문의 낱말을 많이 공유하지만 소개의 마지막 문장에서 질문의 조건 하나를 다루지 않는다고 밝힙니다. 나머지 30권(book01~book30)은 데이터 분석·머신러닝·통계와 천문·생물·역사·문학·기하 도서로, 질문과 관련 없는 책이 섞인 도서 목록을 만듭니다. `demo_questions.json`의 답안은 사람이 작성한 참고 답안이며 검색 순위나 모델 출력이 아닙니다.

## 실제 문서의 출처와 분류

실제 문서 44절, 매뉴얼 질문 82개, PDF 원본은 `day47_하이브리드검색_질의변환/data/`에서 파일 내용 그대로 복사했습니다. 이 폴더에 모두 포함되어 있으므로 학생은 앞 단원 폴더 없이 자료를 읽을 수 있습니다. 문서 본문, 순서, ID, URL, 메타데이터를 변경하지 않았습니다.

[유연근무 활용 매뉴얼 원본 PDF](originals/MOEL_flexible_work_manual_2024.pdf)는 [고용노동부 일·생활 균형의 원문 게시 페이지](https://www.worklife.kr/website_renew/index/newsroom/press_releases_view.asp?GUID=B1C5B341-D745-40C5-9D6B-769F3D75E921)에서 제공한 파일입니다. 발췌 범위는 40개 PDF 페이지의 44절입니다. `metadata.pdf_page`는 PDF 뷰어에서 1부터 세는 페이지이며 본문에 인쇄된 쪽수와 다릅니다.

매뉴얼의 `metadata.category`는 수업용 분류인 공통 11절, 시차출퇴근 9절, 선택근무 9절, 재택근무 15절입니다.

매뉴얼은 2024년 문서를 고정한 학습 자료입니다. 각 문서의 수집 출처는 레코드의 `url`과 `source`에서 확인할 수 있습니다.

## 과제용 가상 사내 문서

과제 문서는 수업을 위해 창작했으며 실제 회사의 정보가 아닙니다. `source`는 `수업용 가상 사내 문서`, `url`은 빈 문자열입니다. 헬프데스크 도움말의 `metadata`에는 분야(`category`)와 최종 수정 월(`updated`)이, 사내 규정에는 분야(`category`)·담당 부서(`department`)·시행일(`effective`)이 있습니다. 규정 본문은 조항마다 줄을 바꿨습니다. 질문 파일의 `evidence`와 `reference_answer`는 사람이 원문을 읽고 작성한 것이며 검색 순위나 모델 출력이 아닙니다.

`sources.json`은 실제 문서의 기존 출처 항목을 보존하고 `copied_from`에 앞 단원 경로를 기록합니다. 시연 자료 항목은 가상 도서 소개와 질문을, 과제 자료 항목은 가상 사내 문서와 질문을 설명합니다.

## 실습 결과

리랭킹 점수·압축 결과·모델 답변은 데이터에 미리 넣지 않았습니다. 노트북에서 만든 결과는 `output/`에 저장합니다. 압축 결과를 읽을 때에는 원문의 조건과 예외가 남았는지 함께 확인합니다.
