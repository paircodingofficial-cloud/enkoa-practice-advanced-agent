# LangGraph 기초

State로 데이터를 전달하고, 작업을 노드로 나눠 고정·조건부 엣지로 연결합니다.

## 학습 순서

| 자료 | 내용 |
|---|---|
| [교안 01](교안_01_State_노드_엣지.ipynb) | State·노드·고정 엣지, 메시지 리듀서, 회의 후속 업무 |
| [교안 02](교안_02_조건부분기_RAG_그래프.ipynb) | Jev 판정, BM25·Dense·RRF 검색 노드, 조건부 엣지와 인용 답변 |
| [교안 03](교안_03_도구선택_검색라우팅.ipynb) | hybrid·graph·combined 검색 경로를 연결하는 통합 실습 |
| [과제 LV1](과제_LV1_기초.ipynb) | 장애 인수인계와 후속 대화 그래프 |
| [과제 LV2](과제_LV2_응용.ipynb) | 공유 작업실 안내문을 검색하는 조건부 RAG 그래프 |

교안 01 → 02 → 03 순서로 진행합니다. 교안 03은 State·노드·엣지를 직접 연결하며, 마지막에 독립 실행용 핵심 코드를 제공합니다.

## 환경 준비

저장소 루트에서 실행합니다.

```bash
uv sync --frozen
```

1. VS Code 커널로 저장소의 `.venv`를 선택합니다.
2. 실습할 day50 폴더의 `.env.example`을 `.env`로 복사하고 본인의 연결 정보를 입력합니다.
3. 노트북 파일이 있는 폴더를 작업 디렉터리로 사용합니다.

| 환경변수 | 용도 |
|---|---|
| `OPENAI_API_KEY` | LLM과 질문 임베딩 |
| `OPENAI_CHAT_MODEL` | 채팅 모델; 기본값 `gpt-5.6-luna` |
| `TYPESAFE_API_KEY` | Jev 질문 판정·검색 경로 선택 |
| `TYPESAFE_MODEL` | `jev-1.13.0` |
| `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD` | 교안 03의 영화 그래프 DB |

교안 01·02와 과제는 Neo4j가 필요하지 않습니다. 교안 03은 **Neo4j 2026.09 이상·Cypher 25·APOC**인 별도 실습 DB를 준비합니다. Python 패키지는 uv가 설치하고, Neo4j·APOC는 서버에 준비합니다. [Neo4j 준비](../day49_Graph_Vector_하이브리드/README.md)

교안 03 준비 A는 영화 데이터를 적재하고 기존 대상 검색 인덱스를 정리해 영화 전용 인덱스로 만듭니다. 학습용 DB에서 진행하세요. 배포된 벡터를 사용하므로 문서 임베딩을 다시 생성하지 않습니다.

## 실행 방법

- 교안 01의 상담 그래프는 `input()`으로 질문을 받습니다. `/종료`를 입력하면 끝납니다.
- 교안 02는 메모리 Chroma의 Dense 검색과 BM25 결과를 가중 RRF로 합칩니다.
- 교안 03은 질문에 따라 줄거리 검색, 관계 조회, 두 검색의 결합 중 필요한 경로를 실행합니다.
- 실행 셀에서 GPT·Jev·질문 임베딩 API를 호출합니다. 그래프를 다시 실행하면 해당 호출도 다시 발생합니다.
- 답변에 인용한 ID가 실제 원문·관계 근거와 일치하는지 확인합니다.
