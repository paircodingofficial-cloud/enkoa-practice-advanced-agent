# 야외 행사 우천 시 인수 장소 확인

운영팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

야외 팝업 행사 고객에게는 비가 올 때 상자를 인수할 실내 장소나 덮개가 있는 하역 위치가 준비돼 있는지 확인합니다. 키트 포장이 우천에 노출돼도 안전하다고 추정하지 않습니다. 행사장 안내가 바뀌면 고객의 현장 담당자와 납품 위치를 다시 확인하고 기존 주소만 보고 운송을 지시하지 않습니다. 날씨 때문에 운송이 가능한지, 실제 도착 시간을 유지할 수 있는지는 당시 운송 상황을 확인해야 합니다. 일반 공유 문서에는 실시간 날씨나 운송 상태가 없습니다.
