# 행사키트 일부를 사무실로 나눠 보내는 경우

운영팀 · FAQ · v1 · 검색 사용

## 업무 지식

행사키트 일부를 고객사 사무실에 보내려면 행사장 수량과 사무실 수량을 주문서에서 나눠 확정합니다. 사무실 주소만으로 행사장 납품 정보를 대신하지 않습니다. 두 목적지의 운송 조건과 일정은 각각 확인합니다. 각 목적지에는 수령 담당자와 반입 가능한 시간을 별도로 적습니다. 사무실과 행사장 주소의 수량 합계가 주문서와 맞는지 확인하고 어느 쪽에 보내는 물품인지 상자 표시로 구분합니다. 행사장 운송 시간과 일반 택배의 예상 이동 기간을 같은 기준으로 설명하지 않습니다.
