# 로고 슬리브 행사키트 제작·납품 일정

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

고객이 행사일을 기준으로 제작과 운송이 모두 가능한지 물었다. 슬리브 승인과 행사장 반입 자료의 상태가 한눈에 보이지 않았다.

## 작업 내역

운영 담당자는 주문서·슬리브 승인·입금·반입 자료를 항목별로 대조했다. 슬롯 확인, 제작, 행사장 운송 확정을 다른 단계로 표시하고 미확정 정보는 날짜 계산에 넣지 않았다.

## 확인한 기준

팝업 행사키트는 확정 주문서, 최종 슬리브 시안 승인, 입금 완료와 행사장 반입 자료를 모두 받은 뒤 운영팀이 생산 슬롯을 확인해 제작 시작일을 확정합니다. 기본 구성에 슬리브를 씌우는 표준 제작은 확정 시작일부터 5영업일입니다. 영업일은 토요일·일요일·공휴일을 제외합니다. 제작 뒤 행사장 일괄 운송 일정은 별도로 확정하며 이 문서만으로 행사일 도착을 보장할 수 없습니다.

## 후속 작업

시작 조건을 확인한 뒤 실제 생산 슬롯과 제작 시작일을 정한다. 제작 후 운송 일정은 별도로 확정해 안내한다.
