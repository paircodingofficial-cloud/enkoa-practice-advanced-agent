# 키트 납품과 부스 설치의 경계

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

현장 고객이 상자 인계 외에 개봉과 부스 진열도 운송 담당자가 맡아 달라고 요청했다.

## 작업 내역

담당자는 승인 장소 상자 인계와 추가 진열 요청을 분리해 영업팀에 전달했다. 배너·전기 연결·방문객 배포 등 기본 납품 밖의 작업은 확정 범위로 기록하지 않았다.

## 확인한 기준

모아기프트 운영팀의 행사장 납품은 승인된 장소에서 상자를 인계하는 작업입니다. 부스 진열, 배너 설치, 전기 연결과 방문객 배포는 기본 납품 작업에 포함하지 않습니다. 현장 준비가 필요한 경우 고객이 담당자를 별도로 배정합니다. 고객이 상자를 개봉해 진열해 달라고 요청하면 담당자는 기본 인수 작업과 달라지는 내용을 영업팀에 공유합니다. 현장 작업 가능 여부가 확인되기 전에는 운송 담당자가 모두 해 줄 것처럼 안내하지 않습니다. 행사장의 승인이나 안전 지침은 고객이 전달한 실제 안내로 확인합니다.

## 후속 작업

고객이 배정할 현장 담당자와 실제 행사장 안내를 확인한다. 추가 작업 가능 여부 확인 전 운송 담당자의 수행을 약속하지 않는다.
