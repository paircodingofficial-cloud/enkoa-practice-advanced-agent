# 행사 종료 후 자재 회수 요청

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

행사 종료 후 남은 상자와 진열 자재를 함께 회수해 달라는 요청이 들어왔다. 소유와 작업 범위가 섞여 있었다.

## 작업 내역

운영 담당자는 대상·수량·인수 위치·가능 시간대를 받아 모아기프트 제공품과 고객 소유품을 나누었다. 회수와 폐기·철거를 별도 범위로 정리해 영업팀에 전달했다.

## 확인한 기준

고객이 행사 종료 뒤 남은 상자나 진열 자재를 회수해 달라고 요청하면 운영팀은 대상, 수량, 인수 위치와 가능한 시간대를 별도로 확인합니다. 행사키트를 납품했다는 사실만으로 폐기물 처리나 진열물 철거까지 기본 제공되는 것은 아닙니다. 회수 대상이 모아기프트 제공품인지 고객 소유품인지 구분하고 필요한 작업 범위를 영업팀과 협의합니다. 현장 담당자에게 확인하지 않은 시간에 회수 차량이 간다고 약속하지 않습니다.

## 후속 작업

현장 담당자와 가능한 인수 시간을 확인하고 작업 범위를 협의한다. 확인되지 않은 회수 차량 도착 시간을 약속하지 않는다.
