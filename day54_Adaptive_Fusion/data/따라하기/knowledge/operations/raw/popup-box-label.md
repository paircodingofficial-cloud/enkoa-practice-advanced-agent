# 행사장 납품 상자와 인수 확인

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

행사 부스 구분명이 바뀌어 기존 상자 표기와 현장 인수 장소를 다시 맞춰야 했다.

## 작업 내역

운영 담당자는 행사명·부스명·상자 번호·수량표를 대조하고 최신 표기 확인을 요청했다. 전체 수량 합계와 현장 수령 확인은 다른 항목으로 두고 일부 인수 시 남은 상자와 위치를 남기도록 기록을 나누었다.

## 확인한 기준

행사키트 상자에는 행사명, 부스명, 상자 번호와 담긴 수량을 표기합니다. 운영팀은 전체 상자의 합계가 주문 수량과 맞는지 확인하고 현장 담당자의 수령 확인을 받습니다. 개별 방문객 이름으로 포장하지 않습니다. 현장 담당자가 부스 구분명을 바꾸면 최신 표기와 배치 장소를 확인합니다. 상자 인수 확인은 내용물을 방문객에게 모두 배포했다는 뜻이 아닙니다. 일부 상자만 인수한 경우 남은 상자 수와 위치를 따로 남기고 전체 주문을 한 번에 완료 처리하지 않습니다.

## 후속 작업

현장 담당자와 최신 부스명·배치 장소를 확인한다. 상자 인수를 방문객 배포 완료와 동일하게 처리하지 않는다.
