# 공동 주최·협찬사 정보 접수 — 고객 문의 검토 기록

## 접수·논의 배경

공동 주최 행사에서 협찬사 로고와 협찬 물품까지 한 번에 요청하는 상황이었다.

## 작업 내역

로고의 회사·순서·확인 담당과 추가 물품의 배포·보관 범위를 나눴다. 대행사의 파일 전달이 사용 확인까지 뜻하는지 추정하지 않았다.

## 확인된 사항

행사에 공동 주최사나 협찬사가 참여하면 영업팀은 로고를 넣을 회사, 표기 순서와 확인 담당자를 고객에게 요청합니다. 행사 운영 대행사가 로고 파일을 전달했다고 사용 승인까지 완료된 것으로 간주하지 않습니다. 기본 고객 로고 슬리브와 달라지는 작업 범위는 브랜드팀과 확인합니다. 현장 협찬물 배포나 협찬사별 물품 보관 요청은 키트 제작 계약과 별도인지 구분해 안내합니다. 각 회사의 실명이나 실제 담당자 연락처는 수업용 기록에 넣지 않습니다.

## 후속 작업

브랜드팀과 바뀐 범위를 확인하고 계약 밖 현장 업무는 별도 협의한다.
