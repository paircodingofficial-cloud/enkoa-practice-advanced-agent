# 행사 후 남은 키트 문의

영업팀 · FAQ · v1 · 검색 사용

## 업무 지식

행사 종료 후 남은 고객 로고 키트의 보관이나 추가 배송 요청은 영업팀이 주문 번호와 수량을 받아 별도로 협의합니다. 맞춤 인쇄물의 처리 방법을 문서에 없는 조건으로 약속하지 않습니다. 이 자료는 가상 업무 안내이며 소비자법이나 반품 규정 설명이 아닙니다. 문의를 받을 때는 미개봉 상자와 이미 현장에 배포한 물품을 구분합니다. 창고 보관, 다른 장소로의 운송, 고객의 현장 처리는 각각 다른 작업이므로 필요 범위를 확인합니다. 행사일이 지났다는 이유만으로 자동 회수되거나 다음 행사까지 무상 보관된다고 안내하지 않습니다.
