# 행사 일정 변경·연기 문의

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

고객이 팝업 날짜를 변경하면 영업팀은 인쇄 문구, 제작 진행 상태, 물품 보관과 행사장 납품 예약에 미칠 영향을 함께 확인합니다. 행사일 변경만으로 모든 작업 일정이 자동 이동하는 것은 아닙니다. 이미 인쇄된 행사 날짜가 있는지 브랜드팀에 확인하고 새 제작이나 보관이 필요한지는 운영팀과 협의합니다. 변경 가능 범위와 비용·새 일정은 확인 후 안내하며 현행 문서에 없는 취소 조건을 만들어 답하지 않습니다. 기존 주문과 변경 요청을 연결해 이력을 남깁니다.
