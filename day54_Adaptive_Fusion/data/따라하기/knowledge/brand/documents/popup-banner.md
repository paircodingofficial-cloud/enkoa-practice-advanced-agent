# 키트 슬리브와 행사장 배너 구분

브랜드팀 · FAQ · v1 · 검색 사용

## 업무 지식

행사장 배너는 로고 슬리브와 인쇄 크기·재질이 다릅니다. 같은 행사 로고를 사용해도 슬리브 시안을 배너 제작 파일로 전달하지 않습니다. 배너를 추가 요청하면 출력 규격과 제작 범위를 별도로 확인합니다. 배너 문의에는 설치 위치, 고객이 받은 출력 규격과 최종 문구를 함께 전달받습니다. 슬리브 승인본과 배너 수정본을 같은 이름으로 보관하지 않고 어떤 매체에 사용할 자료인지 표시합니다. 배너 시안이 준비됐다는 사실은 행사장 설치나 철거가 포함된다는 의미가 아닙니다.
