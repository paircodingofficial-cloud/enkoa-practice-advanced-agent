# 행사 날짜가 다른 홍보물의 버전 확인

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

슬리브, 온라인 초대장, 행사장 배너의 날짜 표기가 서로 다르면 브랜드팀은 어느 자료가 최신인지 고객 담당자에게 확인합니다. 파일 이름의 날짜가 더 최근이라는 이유만으로 최종 승인 내용까지 바뀌었다고 판단하지 않습니다. 변경이 확인되면 아직 인쇄 전인 자료와 이미 제작한 자료를 나누어 수정 범위를 협의합니다. 수정된 문구의 최종 승인과 행사장 납품 일정 확인은 별개입니다. 이 기록은 특정 행사 변경 이력을 관리하는 방법이며 행사일을 자동 확정하는 규칙이 아닙니다.
