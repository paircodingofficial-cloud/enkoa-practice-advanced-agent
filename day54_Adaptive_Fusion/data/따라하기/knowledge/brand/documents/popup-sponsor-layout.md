# 공동 행사 슬리브의 여러 로고 배치

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

공동 주최 팝업의 슬리브에는 각 회사 로고 원본과 표시 순서를 받아야 합니다. 브랜드팀은 로고 크기와 여백이 서로 충돌하지 않는지 확인하고 고객의 최종 승인 창구에 한 시안으로 전달합니다. 로고가 많아져 읽기 어렵다면 배치 대안을 제안하지만 협찬사 우선순위를 자체 판단하지 않습니다. 회사별 사용 조건을 확인한 기록과 최종 승인 파일을 연결합니다. 단일 로고용 이전 시안을 파일 추가만으로 최종본 처리하지 않습니다.
