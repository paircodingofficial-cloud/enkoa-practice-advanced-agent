# 행사 로고 슬리브 제작 자료

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

팝업 행사 로고 슬리브는 고객 로고의 AI 또는 SVG 원본, 최종 행사명·행사 날짜·인쇄 문구, 원하는 색상과 표시 순서를 받습니다. 브랜드팀이 제공하는 해당 키트 전개도에 맞춰 배치하며 예전 행사 슬리브 크기를 재사용하지 않습니다. 고객이 제공 자료의 사용 가능 여부를 확인합니다. QR을 넣는 경우에는 공개할 최종 연결 주소도 함께 받습니다.
