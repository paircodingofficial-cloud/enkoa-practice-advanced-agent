# 공동 행사 슬리브의 여러 로고 배치 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 담당: 브랜드팀
- 자료 종류: 업무가이드
- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

공동 행사 슬리브에서 여러 회사 로고의 순서와 크기에 다른 의견이 제시되는 상황이었다.

## 작업 내역

각 원본·표시 순서·여백·최종 확인 창구를 나눴다. 협찬사 우선순위를 브랜드팀이 자체 판단하지 않고 고객 질문으로 남겼다.

## 확인된 사항

공동 주최 팝업의 슬리브에는 각 회사 로고 원본과 표시 순서를 받아야 합니다. 브랜드팀은 로고 크기와 여백이 서로 충돌하지 않는지 확인하고 고객의 최종 승인 창구에 한 시안으로 전달합니다. 로고가 많아져 읽기 어렵다면 배치 대안을 제안하지만 협찬사 우선순위를 자체 판단하지 않습니다. 회사별 사용 조건을 확인한 기록과 최종 승인 파일을 연결합니다. 단일 로고용 이전 시안을 파일 추가만으로 최종본 처리하지 않습니다.

## 후속 작업

배치 대안과 사용 조건을 묶어 최종 승인 파일로 연결한다.
