# 행사 날짜가 다른 홍보물의 버전 확인 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 담당: 브랜드팀
- 자료 종류: 업무가이드
- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

슬리브·배너·온라인 초대장의 날짜가 다르게 보여 최신 정보가 무엇인지 확인하는 상황이었다.

## 작업 내역

파일 이름의 날짜와 고객의 승인 내용은 별개로 읽었다. 아직 제작 전인 자료와 이미 인쇄한 자료의 변경 가능 범위를 나눴다.

## 확인된 사항

슬리브, 온라인 초대장, 행사장 배너의 날짜 표기가 서로 다르면 브랜드팀은 어느 자료가 최신인지 고객 담당자에게 확인합니다. 파일 이름의 날짜가 더 최근이라는 이유만으로 최종 승인 내용까지 바뀌었다고 판단하지 않습니다. 변경이 확인되면 아직 인쇄 전인 자료와 이미 제작한 자료를 나누어 수정 범위를 협의합니다. 수정된 문구의 최종 승인과 행사장 납품 일정 확인은 별개입니다. 이 기록은 특정 행사 변경 이력을 관리하는 방법이며 행사일을 자동 확정하는 규칙이 아닙니다.

## 후속 작업

고객이 확인한 날짜를 받아 각 자료의 수정 범위와 별도 납품 영향을 연결한다.
