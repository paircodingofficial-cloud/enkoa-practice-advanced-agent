# 완성품 임시 보관과 상자 표기

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

같은 고객사의 서로 다른 구성 버전 완성품이 같은 출고 대기 구역에 놓였다. 외부 표시만으로는 묶음을 구별하기 어려웠다.

## 작업 내역

운영 담당자는 주문 번호와 구성표 버전으로 묶음을 나누고 고객 지정 구분명을 상자 표시와 작업표에 연결했다. 보관 위치를 기록하고 불필요한 수령인 연락처는 외부 표시 항목에서 제외했다.

## 확인한 기준

출고 대기 중인 완성품은 주문 번호와 구성표 버전으로 구분합니다. 상자 겉면에는 고객사 담당자가 지정한 구분명을 사용하고 개별 수령인의 전체 연락처를 불필요하게 표시하지 않습니다. 보관 위치와 출고 묶음은 작업표에 기록합니다. 같은 고객사의 주문이 여러 건이어도 행사나 구성 버전이 다르면 같은 묶음으로 처리하지 않습니다. 출고 담당자는 상자 표시와 작업표를 대조하고 모르는 상자를 임의로 합치지 않습니다. 이 보관 표시는 실제 택배 발송이나 고객 수령이 완료됐다는 뜻이 아닙니다.

## 후속 작업

출고 담당자는 상자 표시와 작업표를 대조한다. 식별되지 않는 상자를 합치지 않고 확인 요청으로 남긴다.
