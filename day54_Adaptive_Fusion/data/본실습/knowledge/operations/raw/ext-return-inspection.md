# 회수된 물품의 상태 확인 기록

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

회수 상자의 요청 내역과 도착 상태를 대조할 필요가 있었다. 고객 사진에서 보인 문제만으로 원인을 단정할 수 없었다.

## 작업 내역

입고 담당자는 연결 주문과 회수 요청을 대조하고 실제 품목·수량·포장 상태를 기록했다. 고객 사진의 내용과 도착 후 관찰을 분리했으며 재사용 판단 전 물품은 정상 재고와 구분했다.

## 확인한 기준

회수 상자를 받으면 연결 주문과 회수 요청 내역을 대조하고 실제 도착 품목·수량·포장 상태를 기록합니다. 고객 사진에서 보인 문제와 도착 뒤 관찰한 상태를 구분해 원인을 추측으로 확정하지 않습니다. 재사용 가능 여부를 확인하지 않은 물품은 정상 재고에 섞지 않습니다. 운영팀은 검토 결과와 추가 확인이 필요한 사항을 영업팀에 전달하고 고객과 합의한 후속 조치를 연결합니다. 회수 수량과 보완 출고 수량이 다르면 그 사유를 남겨 중복 발송이나 누락을 방지합니다.

## 후속 작업

검토 결과와 추가 확인 사항을 영업팀에 전달한다. 고객 합의 후속 조치와 보완 출고를 연결하고 수량 차이는 사유를 남긴다.
