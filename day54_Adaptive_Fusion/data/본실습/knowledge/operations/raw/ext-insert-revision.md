# 사용 안내지 버전과 제품 구성 맞추기

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

대체 구성품으로 변경된 주문에 이전 상품의 사용 안내지가 남아 있었다.

## 작업 내역

작업자는 안내지와 실제 상품을 대조하고 주문별 파일 버전·실물 입고 수량을 기록했다. 이전 안내지는 적용 가능 여부를 브랜드팀에 확인할 대상으로 분리했다. 샘플 점검 항목에 안내지 앞뒷면과 방향을 추가했다.

## 확인한 기준

키트에 제품 사용 안내지를 넣을 때는 안내지에 표시된 상품과 실제 구성품이 맞는지 확인합니다. 대체품으로 바뀌었는데 이전 안내지가 남아 있으면 적용 가능한지 브랜드팀과 확인하기 전까지 그대로 넣지 않습니다. 운영팀은 주문 번호별 안내지 파일 버전과 실물 입고 수량을 기록합니다. 문구나 연결 주소는 승인본을 기준으로 사용하며 포장 작업자가 임의로 수정하지 않습니다. 샘플 키트 점검 때 구성품뿐 아니라 안내지의 앞뒷면과 방향도 함께 대조합니다.

## 후속 작업

브랜드팀 확인과 승인본에 따라 동봉 자료를 정한다. 작업자가 문구나 연결 주소를 임의 수정하지 않는다.
