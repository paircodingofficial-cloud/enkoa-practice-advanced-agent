# 영업일 기준 일정 안내의 범위

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

고객이 상담일에서 제작 기간과 택배 기간을 더해 수령일을 계산해 보냈다. 아직 승인 대기와 슬롯 확인이 남아 있었다.

## 작업 내역

운영 담당자는 자료 보완·승인·슬롯 확인·제작·운송을 단계별로 나누어 회신했다. 영업일 정의는 적되 현재 시작일과 운송 일정이 없으므로 계산 날짜를 납기 약속으로 옮기지 않았다.

## 확인한 기준

모아기프트 문서의 영업일은 토요일·일요일·공휴일을 제외한 날을 뜻합니다. 제작 검토 기간, 제작 기간, 택배의 일반 예상 이동 기간은 서로 다른 단계이므로 단순히 오늘부터 모두 더해 확정 수령일로 안내하지 않습니다. 고객 자료 보완과 승인 대기, 생산 슬롯 확인 시간이 별도로 필요할 수 있습니다. 현재 주문의 시작일과 실제 운송 일정이 없으면 날짜 계산 결과를 납기 약속으로 쓰지 않습니다. 고객에게는 필요한 확인 단계와 확정된 정보만 나누어 전달합니다.

## 후속 작업

남은 확인 단계와 확정 정보를 분리해 영업팀에 전달한다. 시작일이 확인되면 해당 단계의 일정 안내를 갱신한다.
