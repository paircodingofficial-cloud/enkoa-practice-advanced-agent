# 발주 수량과 실제 입고 수량이 다를 때

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

발주서와 입고 수량이 달라 공급사에 잔여분을 문의했다. 추가 발송 답변만으로 현재 사용 가능한 수량을 늘릴 수는 없었다.

## 작업 내역

운영 담당자는 주문 필요 수량·사용 가능한 입고분·부족분을 나누어 기록했다. 추가 입고 예정은 별도 표시하고 영향을 받는 포장 작업을 영업팀에 전달했다. 구성품 축소나 미승인 대체로 차이를 맞추지 않았다.

## 확인한 기준

발주서보다 적게 입고되면 주문별 필요 수량, 사용 가능한 입고 수량과 부족 수량을 나누어 기록합니다. 공급사가 나머지를 보내겠다고 답해도 실제 추가 입고 전에는 가용 수량에 합치지 않습니다. 초과 입고품은 다른 주문에 바로 쓰지 않고 공급사와 처리 방식을 확인합니다. 운영팀은 부족분이 영향을 주는 작업을 표시해 영업팀과 일정 조정을 논의합니다. 수량 차이를 맞추려고 키트당 구성품을 줄이거나 고객이 승인하지 않은 대체품을 넣지 않습니다.

## 후속 작업

실제 추가 입고 뒤 수량을 갱신한다. 초과 입고가 확인되면 다른 주문에 쓰기 전에 공급사와 처리 방식을 확인한다.
