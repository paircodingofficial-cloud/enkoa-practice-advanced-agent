# 월말 창고 수량 차이의 원인 확인

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

월말 장부와 실물 수량 차이가 있어 단순 수치 수정 전에 이동 기록을 대조했다.

## 작업 내역

운영 담당자는 입고·제작 투입·완성품·출고·회수를 품목별로 연결하고 누락 이동과 식별 오류를 확인할 항목으로 정리했다. 확인 중 수량은 가용 재고와 분리하고 조정 사유·근거·담당자를 남길 기록을 마련했다.

## 확인한 기준

월말 수량 대조에서는 입고, 제작 투입, 완성품, 출고와 회수 기록을 품목별로 연결합니다. 재고 장부와 실물 수량이 다르면 차이를 숨기기 위해 숫자만 고치지 않고 누락된 이동이나 품목 식별 오류를 찾습니다. 확인 중 수량은 고객에게 확보 가능한 수량으로 안내하지 않습니다. 운영팀은 조정 사유와 근거 자료, 확인 담당자를 남기고 영향을 받는 주문 배정을 다시 대조합니다. 이 회고 문서의 예전 차이 수치를 현재 재고 상태로 해석하지 않도록 점검 일자를 분명히 기록합니다.

## 후속 작업

확인 결과에 따라 관련 주문 배정을 다시 대조한다. 과거 점검 수치를 현재 재고 상태로 안내하지 않는다.
