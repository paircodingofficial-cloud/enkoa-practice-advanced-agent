# 입사 차수별 키트 보관·출고 목록

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

입사 차수별로 선물을 보내는 주문에서 예상 인원과 확정 명단, 완성 수량이 한 목록에 섞여 있었다.

## 작업 내역

운영 담당자는 차수·배정 수량·완성 수량·발송 지시를 나누고 예상 인원은 확정 수령인과 분리했다. 보관 중 구성·상자 문구 변경은 기존 완성품 사용 가능 여부를 확인할 항목으로 남겼다.

## 확인한 기준

고객이 입사 차수별 출고를 협의한 주문은 차수, 배정 수량, 실제 완성 수량과 발송 지시 상태를 목록으로 관리합니다. 예상 입사 인원은 확정 수령인 수와 나누어 표시합니다. 보관 중 구성이나 인쇄 문구가 바뀌면 기존 완성품을 새 요청에 그대로 사용할 수 있는지 확인합니다. 차수별 명단이 확정되기 전에는 이전 명단을 복사해 출고하지 않습니다. 영업팀과 합의된 보관·배송 범위 안에서 작업하고, 각 회차의 출고 합계와 남은 수량을 전체 주문과 대조합니다. 개별 배송 명단의 제출 시점은 operations:split-shipping 기준을 따르며, 변경이 필요하면 운영팀에 별도 확인합니다.

## 후속 작업

차수별 확정 명단을 받아 출고 합계와 남은 수량을 주문 전체와 대조한다. 명단 시점 변경이 필요하면 split-shipping 기준과 운영팀 확인을 따른다.
