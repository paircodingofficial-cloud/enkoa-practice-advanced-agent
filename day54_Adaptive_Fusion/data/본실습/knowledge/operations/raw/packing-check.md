# 포장 단계 구성품 확인

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

포장 작업표에 붙은 구성표가 고객의 현재 승인본과 달라 메시지 카드 누락 가능성이 발견됐다.

## 작업 내역

작업자는 이전 구성표를 작업 기준에서 분리하고 현재 승인본과 포장 작업표를 대조했다. 상자 로고 인쇄물·메시지 카드·고객 제공품을 각각 점검 항목에 넣었다. 영향을 받을 수 있는 작업 묶음은 재확인 대상으로 표시했다.

## 확인한 기준

운영팀은 승인된 구성표와 포장 작업표를 대조해 신입사원 선물 세트별 누락·혼입을 확인합니다. 로고 인쇄물과 메시지 카드도 구성품에 포함합니다. 샘플 점검 결과에 문제가 있으면 같은 작업 묶음을 다시 확인한 뒤 출고 여부를 판단합니다. 작업자는 이전 주문의 구성표가 아닌 현재 승인된 버전을 사용합니다. 고객 제공 물품이 포함된 경우 실제 입고 수량도 대조합니다. 검사 중 발견한 부족 품목과 조치 상태를 기록하고, 다른 품목으로 임의 대체해 수량만 맞추지 않습니다.

## 후속 작업

부족 품목과 조치 상태를 기록해 운영 담당자가 출고 여부를 판단한다. 미승인 대체품으로 수량만 맞추지 않는다.
