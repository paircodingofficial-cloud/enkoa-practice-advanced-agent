# 긴급 작업 요청이 기존 주문에 미치는 영향

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

급한 보완 출고 요청이 기존 확정 주문의 공정과 겹칠 가능성이 있었다.

## 작업 내역

운영 담당자는 필요 공정·수량·준비 자료·요청 사유를 받아 기존 작업 순서의 영향 범위를 정리했다. 긴급 접수와 우선순위 확정을 다른 상태로 표시하고 영업팀의 급행 표시만으로 다른 주문을 뒤로 미루지 않았다.

## 확인한 기준

긴급 제작이나 보완 출고 요청이 들어오면 필요한 공정, 수량, 준비된 자료와 요청 사유를 확인합니다. 운영팀은 기존 확정 주문의 작업 순서를 바꿔야 하는지 검토하고 영향 범위를 담당자에게 공유합니다. 영업팀의 급행 표시만으로 이미 확정된 다른 주문을 뒤로 미루지 않습니다. 일정 조정이 가능한 경우에만 변경 내용을 회신하고 관련 작업표에 반영합니다. 긴급 요청 접수와 작업 우선순위 확정은 다른 상태이며 이전 긴급 처리 사례의 소요 시간을 새 약속으로 쓰지 않습니다.

## 후속 작업

일정 조정이 가능한 경우에만 변경 회신과 작업표를 함께 갱신한다. 이전 긴급 처리 시간을 새 약속에 사용하지 않는다.
