# 주문별 재고 확보 상태 장부

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

같은 품목이 상담 예상 수량과 다른 주문 배정 수량에 함께 나타나 중복 약속 가능성을 점검했다.

## 작업 내역

재고 담당자는 품목·요청 수량·연결 주문·확보 여부·남은 조건을 장부에 구분했다. 입고 예정은 현재 창고 수량과 떨어뜨려 표시하고 이미 배정된 수량을 별도로 식별했다. 공유 기록에 실시간 잔여 수량을 추정해 적지 않았다.

## 확인한 기준

재고 확보 장부에는 품목, 요청 수량, 연결 주문, 확보 확인 여부와 남은 확인 조건을 기록합니다. 상담에서 제시한 예상 수량과 이미 다른 주문에 배정된 수량을 구분해야 같은 물품을 두 주문에 약속하지 않습니다. 입고 예정 물품은 현재 창고 수량과 별도 표시합니다. 이 문서는 장부 작성 방법이며 현재 잔여 재고나 확보 가능 수량을 제공하지 않습니다. 주문 변경이나 취소가 확인되면 관련 배정 기록도 대조하고, 담당자 확인 없이 확보 상태를 유지하거나 해제하지 않습니다.

## 후속 작업

주문 변경·취소가 확인되면 담당자와 배정 기록을 대조한다. 확인 없이 확보 상태를 유지하거나 해제하지 않는다.
