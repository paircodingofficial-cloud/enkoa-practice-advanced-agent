# 배송 라벨 재출력 시 구라벨 처리

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

주소 수정으로 라벨을 재출력하면서 기존 라벨이 다른 상자에 붙을 가능성이 생겼다.

## 작업 내역

작업자는 구라벨과 신라벨이 같은 수령 건인지 대조하고 사용 여부를 분리했다. 새 운송장과 출고 기록의 연결을 갱신할 항목을 표시했으며, 라벨 재출력을 택배사 주소 변경 완료로 안내하지 않았다.

## 확인한 기준

주소 수정이나 출력 오류로 배송 라벨을 다시 만들 때는 기존 라벨과 새 라벨이 같은 수령 건인지 먼저 대조합니다. 구라벨이 상자에 남거나 별도 상자에 붙지 않도록 사용 여부를 구분합니다. 새로운 운송장이 발급되었다면 출고 기록에도 연결을 갱신하고 이전 운송장 상태를 확인합니다. 라벨 재출력만으로 주소 수정이 택배사에 반영됐다고 안내하지 않습니다. 실제 상자에 붙은 라벨과 확정 명단을 마지막으로 대조해 두 번 발송되거나 다른 사람에게 전달되는 일을 막습니다.

## 후속 작업

이전 운송장 상태를 확인하고 실제 부착 라벨과 확정 명단을 마지막으로 대조한다.
