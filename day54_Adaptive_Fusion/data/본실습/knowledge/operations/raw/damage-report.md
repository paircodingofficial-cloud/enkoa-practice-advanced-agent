# 수령 후 파손 문의 접수

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

수령 후 선물 상자 손상과 내용물 파손 문의가 함께 접수됐다. 서로 다른 수령인의 문의를 같은 원인으로 묶을 근거는 없었다.

## 작업 내역

접수 담당자는 주문 번호·품목·수량·사진을 요청하고 상자와 내용물 손상을 구분했다. 수령 건별로 문의를 나누어 운영팀에 전달했으며 사진에서 확인되는 상태와 아직 모르는 원인을 별도 칸에 적었다.

## 확인한 기준

고객이 파손을 알리면 주문 번호, 파손 품목과 수량, 확인 사진을 받아 운영팀에 전달합니다. 원인 확인 후 보완 방법과 일정을 회신합니다. 이 문서는 가상 회사의 문의 처리 절차이며 법적 보상 기준이 아닙니다. 접수자는 상자와 내용물 중 무엇이 손상됐는지 구분해 기록하고, 다른 수령인의 문의를 같은 사건으로 단정하지 않습니다. 사진만으로 원인이나 책임을 확정하지 않으며 검토 중인 항목은 고객에게 그대로 알립니다. 보완하기로 확인한 수량과 실제 발송한 수량도 따로 남깁니다.

## 후속 작업

운영팀이 원인을 검토한 뒤 보완 방법과 일정을 회신한다. 보완 합의 수량과 실제 발송 수량은 각각 남긴다.
