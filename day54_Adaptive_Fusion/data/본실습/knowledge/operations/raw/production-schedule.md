# 신입사원 선물 세트 제작 일정과 시작 조건

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

영업팀이 신입사원 선물 80세트의 제작 일정을 문의했다. 주문 상담 내역에는 희망 수령일이 있었지만 주문서 확정·상자 로고 승인·입금 확인 자료가 한곳에 모여 있지 않았다.

## 작업 내역

운영 담당자는 영업팀의 전달 목록을 시작 조건별로 대조했다. 주문 접수와 시작일 확정을 분리하고, 근거가 첨부되지 않은 항목은 미확인으로 표시했다. 생산 슬롯 확인 전이므로 출고일 칸은 채우지 않았다.

## 확인한 기준

고객 로고 신입사원 선물 세트는 확정 주문서, 최종 로고 시안 승인, 입금 완료가 모두 확인된 뒤 운영팀이 생산 슬롯을 확인해 제작 시작일을 확정합니다. 표준 제작 기간은 확정된 제작 시작일부터 7영업일입니다. 영업일은 토요일·일요일·공휴일을 제외합니다. 이 공유 문서에는 현재 생산 슬롯이 없으므로 접수일만으로 출고일을 계산하거나 보장하지 않습니다. 택배 이동 기간은 제작 기간에 포함하지 않습니다.

## 후속 작업

영업팀은 누락된 확인 자료를 모아 전달한다. 운영팀은 조건 확인 후 생산 슬롯을 조회해 시작일 확정 여부를 회신한다.
