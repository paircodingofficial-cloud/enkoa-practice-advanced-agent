# 파손 확인품의 택배 회수 접수

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

파손품을 직접 확인하기로 협의했지만 회수 대상과 물품 위치가 접수 기록에 흩어져 있었다.

## 작업 내역

운영 담당자는 품목·수량·위치·포장 상태를 모아 적고 고객 담당자와 연락 창구를 정리했다. 회수 신청·기사 인수·창고 도착은 별도 단계로 표시하고 보완 발송 기록은 연결하되 수량을 자동 일치시키지 않았다.

## 확인한 기준

파손품을 직접 확인하기로 협의하면 회수할 품목·수량, 물품 위치와 포장 상태를 먼저 기록합니다. 운영팀은 고객 담당자와 회수 가능한 연락 창구를 정하고 택배 접수 여부를 확인합니다. 회수 신청, 기사 인수와 창고 도착은 다른 단계이므로 신청만으로 물품을 받은 것으로 표시하지 않습니다. 회수품과 보완 발송품은 연결하되 같은 수량으로 자동 처리하지 않습니다. 회수 방법이나 추가 운송 조건은 실제 확인 뒤 안내하며, 이 절차를 모든 파손 문의에 일괄 적용하는 보상 규정으로 설명하지 않습니다.

## 후속 작업

택배 접수와 실제 이동 상태를 확인해 갱신한다. 회수 방법과 추가 운송 조건은 확인 뒤 안내한다.
