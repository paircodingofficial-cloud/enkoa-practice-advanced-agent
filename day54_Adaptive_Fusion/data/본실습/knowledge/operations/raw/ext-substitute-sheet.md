# 대체 구성품 비교에 필요한 운영 정보

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

재고 부족 품목의 대체 후보가 제시됐지만 같은 가격이라는 설명만 있어 고객이 차이를 판단하기 어려웠다.

## 작업 내역

운영 담당자는 원품과 후보의 크기·재질·기능·색상·포장 적합성을 비교표에 나란히 적었다. 로고 적용 대상의 인쇄 영역은 브랜드팀 확인 항목으로 넘기고 고객 미승인 후보는 확정 구성표와 분리했다.

## 확인한 기준

대체품을 검토할 때는 원래 품목과 후보 품목의 크기, 재질, 사용 기능, 색상 및 포장 적합성을 나란히 기록합니다. 단가가 같다는 이유만으로 동등한 상품이라고 표시하지 않습니다. 로고를 적용하는 품목이면 브랜드팀이 인쇄 영역과 표현 가능 여부를 다시 확인해야 합니다. 영업팀이 고객에게 차이를 설명하고 선택을 확인하기 전에는 후보를 확정 구성표에 넣지 않습니다. 승인 뒤에도 실제 입고품과 비교표가 같은지 확인해 다른 공급품이 섞이지 않도록 합니다.

## 후속 작업

영업팀이 차이를 설명하고 고객 선택을 확인한다. 승인 뒤에도 실제 입고품과 비교표가 같은지 대조한다.
