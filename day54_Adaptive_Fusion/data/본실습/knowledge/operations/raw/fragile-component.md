# 깨지기 쉬운 구성품의 포장 검토

> 수업용 가상 업무 기록

기록일은 2026-10-02이며, `policy_updated`는 확인한 기준자료의 버전 날짜다.

## 문제 상황

고객이 선물 구성에 도자기 품목을 넣어 달라고 요청했다. 기존 상자와 완충재가 그대로 적합한지는 확인되지 않았다.

## 작업 내역

운영 담당자는 제품 크기와 취급 조건을 확인 항목으로 적고 완충·고정 방법을 검토했다. 검토용 포장 사진은 방법 확인 자료로 분류했으며 무파손 보장 근거로 사용하지 않았다.

## 확인한 기준

유리나 도자기처럼 깨지기 쉬운 물품을 구성에 넣으려면 운영팀이 완충 포장과 상자 안 고정 방법을 확인합니다. 기존 표준 키트와 구성품이 다르면 동일한 포장재로 충분하다고 가정하지 않습니다. 포장 방식 변경이 필요하면 구성표와 견적 범위를 영업팀과 함께 갱신합니다. 검토용 포장 사진은 방법 확인 자료이며 모든 운송에서 파손이 없다는 보장은 아닙니다. 고객이 물품을 직접 제공한 경우에도 제품의 실제 크기와 취급 조건을 확인한 뒤 작업 가능 여부를 답합니다.

## 후속 작업

포장 변경이 필요하면 영업팀과 구성표·견적 범위를 함께 갱신한다. 고객 제공품도 실제 조건 확인 후 작업 가능 여부를 답한다.
