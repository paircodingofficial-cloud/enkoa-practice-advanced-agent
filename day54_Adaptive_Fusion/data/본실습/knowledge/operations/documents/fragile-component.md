# 깨지기 쉬운 구성품의 포장 검토

운영팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

유리나 도자기처럼 깨지기 쉬운 물품을 구성에 넣으려면 운영팀이 완충 포장과 상자 안 고정 방법을 확인합니다. 기존 표준 키트와 구성품이 다르면 동일한 포장재로 충분하다고 가정하지 않습니다. 포장 방식 변경이 필요하면 구성표와 견적 범위를 영업팀과 함께 갱신합니다. 검토용 포장 사진은 방법 확인 자료이며 모든 운송에서 파손이 없다는 보장은 아닙니다. 고객이 물품을 직접 제공한 경우에도 제품의 실제 크기와 취급 조건을 확인한 뒤 작업 가능 여부를 답합니다.
