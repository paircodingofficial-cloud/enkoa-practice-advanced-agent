# 대체 구성품 비교에 필요한 운영 정보

운영팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

대체품을 검토할 때는 원래 품목과 후보 품목의 크기, 재질, 사용 기능, 색상 및 포장 적합성을 나란히 기록합니다. 단가가 같다는 이유만으로 동등한 상품이라고 표시하지 않습니다. 로고를 적용하는 품목이면 브랜드팀이 인쇄 영역과 표현 가능 여부를 다시 확인해야 합니다. 영업팀이 고객에게 차이를 설명하고 선택을 확인하기 전에는 후보를 확정 구성표에 넣지 않습니다. 승인 뒤에도 실제 입고품과 비교표가 같은지 확인해 다른 공급품이 섞이지 않도록 합니다.
