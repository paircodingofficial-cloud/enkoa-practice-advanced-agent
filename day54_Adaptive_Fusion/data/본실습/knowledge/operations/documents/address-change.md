# 배송 주소 수정 요청

운영팀 · FAQ · v1 · 검색 사용

## 업무 지식

출고 전 주소 수정은 운영팀이 기존 명단과 수정본을 대조해 반영 여부를 회신합니다. 출고 후에는 운송장 상태를 확인해야 하며 주소 변경이나 재배송 가능 여부를 먼저 확답하지 않습니다. 고객 담당자는 명단 파일을 여러 버전으로 동시에 전달하지 않습니다. 수정 요청에는 바뀌는 행과 해당 수령인을 구분할 정보를 포함합니다. 고객에게서 새 파일이 왔다고 이미 발급한 운송장까지 자동으로 바뀌는 것은 아닙니다. 운영팀이 반영한 버전과 반영하지 못한 건을 나누어 회신해야 중복 발송을 줄일 수 있습니다.
