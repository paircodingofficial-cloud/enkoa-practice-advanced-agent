# 발주 수량과 실제 입고 수량이 다를 때

운영팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

발주서보다 적게 입고되면 주문별 필요 수량, 사용 가능한 입고 수량과 부족 수량을 나누어 기록합니다. 공급사가 나머지를 보내겠다고 답해도 실제 추가 입고 전에는 가용 수량에 합치지 않습니다. 초과 입고품은 다른 주문에 바로 쓰지 않고 공급사와 처리 방식을 확인합니다. 운영팀은 부족분이 영향을 주는 작업을 표시해 영업팀과 일정 조정을 논의합니다. 수량 차이를 맞추려고 키트당 구성품을 줄이거나 고객이 승인하지 않은 대체품을 넣지 않습니다.
