# 파손 확인품의 택배 회수 접수

운영팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

파손품을 직접 확인하기로 협의하면 회수할 품목·수량, 물품 위치와 포장 상태를 먼저 기록합니다. 운영팀은 고객 담당자와 회수 가능한 연락 창구를 정하고 택배 접수 여부를 확인합니다. 회수 신청, 기사 인수와 창고 도착은 다른 단계이므로 신청만으로 물품을 받은 것으로 표시하지 않습니다. 회수품과 보완 발송품은 연결하되 같은 수량으로 자동 처리하지 않습니다. 회수 방법이나 추가 운송 조건은 실제 확인 뒤 안내하며, 이 절차를 모든 파손 문의에 일괄 적용하는 보상 규정으로 설명하지 않습니다.
