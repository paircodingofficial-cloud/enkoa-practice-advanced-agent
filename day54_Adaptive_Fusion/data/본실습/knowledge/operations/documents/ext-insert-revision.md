# 사용 안내지 버전과 제품 구성 맞추기

운영팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

키트에 제품 사용 안내지를 넣을 때는 안내지에 표시된 상품과 실제 구성품이 맞는지 확인합니다. 대체품으로 바뀌었는데 이전 안내지가 남아 있으면 적용 가능한지 브랜드팀과 확인하기 전까지 그대로 넣지 않습니다. 운영팀은 주문 번호별 안내지 파일 버전과 실물 입고 수량을 기록합니다. 문구나 연결 주소는 승인본을 기준으로 사용하며 포장 작업자가 임의로 수정하지 않습니다. 샘플 키트 점검 때 구성품뿐 아니라 안내지의 앞뒷면과 방향도 함께 대조합니다.
