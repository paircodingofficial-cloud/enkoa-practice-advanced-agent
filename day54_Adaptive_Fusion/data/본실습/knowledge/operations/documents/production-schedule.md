# 신입사원 선물 세트 제작 일정과 시작 조건

운영팀 · 업무가이드 · v2 · 검색 사용

## 업무 지식

고객 로고 신입사원 선물 세트는 확정 주문서, 최종 로고 시안 승인, 입금 완료가 모두 확인된 뒤 운영팀이 생산 슬롯을 확인해 제작 시작일을 확정합니다. 표준 제작 기간은 확정된 제작 시작일부터 7영업일입니다. 영업일은 토요일·일요일·공휴일을 제외합니다. 이 공유 문서에는 현재 생산 슬롯이 없으므로 접수일만으로 출고일을 계산하거나 보장하지 않습니다. 택배 이동 기간은 제작 기간에 포함하지 않습니다.
