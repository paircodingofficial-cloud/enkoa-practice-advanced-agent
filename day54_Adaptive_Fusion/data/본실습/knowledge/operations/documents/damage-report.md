# 수령 후 파손 문의 접수

운영팀 · FAQ · v1 · 검색 사용

## 업무 지식

고객이 파손을 알리면 주문 번호, 파손 품목과 수량, 확인 사진을 받아 운영팀에 전달합니다. 원인 확인 후 보완 방법과 일정을 회신합니다. 이 문서는 가상 회사의 문의 처리 절차이며 법적 보상 기준이 아닙니다. 접수자는 상자와 내용물 중 무엇이 손상됐는지 구분해 기록하고, 다른 수령인의 문의를 같은 사건으로 단정하지 않습니다. 사진만으로 원인이나 책임을 확정하지 않으며 검토 중인 항목은 고객에게 그대로 알립니다. 보완하기로 확인한 수량과 실제 발송한 수량도 따로 남깁니다.
