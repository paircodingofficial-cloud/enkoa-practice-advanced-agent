# 급한 신입사원 선물 세트 납기 문의 응대

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

희망 수령일까지 시간이 짧으면 수량, 구성, 로고 유무, 배송 방식을 먼저 확인하고 운영팀에 생산 가능 여부를 문의합니다. 영업팀이 표준 제작 기간을 임의로 줄여 약속하지 않습니다. 급행 요청을 접수한 것만으로 우선 생산이 확정되지 않습니다. 고객이 반드시 맞춰야 하는 행사일과 단순 희망일을 구분해 기록합니다. 운영팀 확인 전에는 상담을 접수했다는 사실과 아직 확정하지 못한 생산·운송 항목을 나누어 전달합니다. 급행 요청 자체가 로고 자료나 고객 승인 절차를 생략하는 근거는 아닙니다.
