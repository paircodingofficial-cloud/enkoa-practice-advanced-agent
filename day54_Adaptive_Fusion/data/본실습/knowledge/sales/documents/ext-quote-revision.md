# 여러 차례 수정한 견적의 변경 사유 관리

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

견적을 다시 보낼 때는 새 버전 번호, 이전 버전과 달라진 항목, 변경 요청자를 함께 적습니다. 구성품 수량과 배송 건수가 동시에 바뀌었다면 금액 차이를 한 줄로 묶지 않고 원인을 나눕니다. 고객에게 비교표를 보내면서 어떤 견적을 확인받아야 하는지 명시하고 이전 첨부본은 참고용으로 표시합니다. 주문서에 적힌 구성과 최신 견적이 다르면 먼저 일치시킨 뒤 확정을 요청합니다. 금액만 수정된 파일을 별도 메시지로 보내 승인 기록이 갈라지는 상황을 피합니다.
