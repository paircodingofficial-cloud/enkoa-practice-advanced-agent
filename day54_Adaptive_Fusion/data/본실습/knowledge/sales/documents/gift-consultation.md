# 행사 목적별 구성 상담

영업팀 · 회의결정 · v1 · 검색 사용

## 업무 지식

입사 축하, 고객 감사, 행사 방문 기념 중 선물 목적과 사용 대상을 먼저 확인합니다. 구성 상담은 상품 추천 단계이며 제작 가능 수량·고객 로고 적용·납기는 주문 단계에서 별도로 확인합니다. 상담자는 사용 장소, 받는 사람의 공통 특성과 꼭 포함할 물품이 있는지 묻습니다. 고객이 정하지 않은 옵션은 추천안으로 표시하고 주문이 확정된 것처럼 운영팀에 전달하지 않습니다. 상품 제안과 고객의 최종 선택을 구분해 다음 담당자가 읽을 수 있게 합니다.
