# 분기 거래 회고에서 반복된 확인 누락 찾기

영업팀 · 프로젝트회고 · v1 · 검색 사용

## 업무 지식

분기 회고에서는 수주 금액만 보지 않고 상담 때 빠진 배송 방식, 승인 담당자, 구성 변경 기록을 주문별로 모읍니다. 같은 고객의 재주문이라도 누락 원인이 다르면 별도 사례로 남깁니다. 팀은 고객이 늦게 준 자료와 내부에서 전달하지 않은 자료를 구분해 개선할 위치를 찾습니다. 개선안에는 사용할 질문이나 서식 항목, 담당자를 적고 막연한 주의 요청으로 끝내지 않습니다. 과거 사례는 새 정책의 근거가 될 수 있지만 회의에서 결정하지 않은 조건을 현행 주문 규정처럼 안내하지 않습니다.

## 적용 범위

이 기록의 과거 사례와 개선 조치는 현재 주문의 확정 일정·금액을 뜻하지 않습니다.
