# 본사 계약과 지점별 요청 창구 구분

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

여러 지점에 키트를 보내는 거래에서는 계약을 승인할 본사 담당자와 지점별 요청자를 먼저 구분합니다. 지점마다 다른 구성이나 문구를 요청하면 본사 승인 여부를 표시한 요청표로 모읍니다. 지점 수와 배송 건수는 다를 수 있으므로 수량표를 별도로 받습니다. 영업팀은 견적 수신처와 주문 승인 창구를 본사에 재확인하며, 지점의 메신저 요청만으로 계약 범위를 바꾸지 않습니다. 제작·배송 가능 여부가 확인되면 변경된 범위를 같은 표에서 고객과 대조합니다.
