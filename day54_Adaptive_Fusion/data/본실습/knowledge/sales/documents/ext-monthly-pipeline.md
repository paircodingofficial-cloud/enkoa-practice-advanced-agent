# 월간 영업 전망에서 확정과 예상 구분

영업팀 · 회의결정 · v1 · 검색 사용

## 업무 지식

월간 영업 회의에서는 문의, 견적 검토, 주문 확정 단계를 나누어 예상 수량을 집계합니다. 고객이 언급한 연간 채용 인원과 이번 주문 수량을 같은 숫자로 기록하지 않습니다. 구성이나 일정이 미정이면 불확실한 항목과 다음 확인일을 남깁니다. 운영팀에 전달하는 전망에는 실제 생산 지시가 아니라는 점을 표시하고, 확정 주문은 주문 번호로 별도 연결합니다. 회의 뒤 단계가 바뀐 건은 변경 이유를 남겨 지난달 전망과 실제 주문 차이를 설명할 수 있게 합니다.
