# 고객 사례 인터뷰 요청과 거래 상담 구분

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

납품 뒤 사용 후기를 요청할 때는 제품 만족도 확인과 외부 공개 인터뷰를 구분해 안내합니다. 고객이 상담 중 칭찬한 문장을 공개 인용문으로 옮기지 않습니다. 사례 인터뷰를 진행한다면 사용할 회사명, 사진, 인용문과 공개 채널을 브랜드팀과 정리해 고객의 확인을 받습니다. 인터뷰에 응하지 않았다는 이유로 기존 주문의 후속 문의를 다른 기준으로 처리하지 않습니다. 영업팀은 최종 공개 승인본의 위치를 남기고 검토 중 원고를 영업 제안서에 먼저 넣지 않습니다.
