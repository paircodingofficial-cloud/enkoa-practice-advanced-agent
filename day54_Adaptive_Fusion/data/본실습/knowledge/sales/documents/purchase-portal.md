# 고객 구매 시스템 등록 요청

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

기업 고객이 구매 시스템에 모아기프트를 등록해 달라고 하면 영업팀이 요청 서류 목록, 고객 담당자와 제출 방식을 확인합니다. 고객 시스템의 등록 완료와 실제 상품 발주는 별도 단계입니다. 구매 시스템 화면에 업체명이 보인다고 견적이나 납기가 승인된 것으로 처리하지 않습니다. 제공할 수 있는 회사 자료는 내부 담당자 확인 후 전달하며 문서에 없는 인증·보험·재무 조건을 임의로 기입하지 않습니다. 서류 요청의 처리 상태와 상품 주문의 진행 상태를 서로 다른 항목으로 기록합니다.
