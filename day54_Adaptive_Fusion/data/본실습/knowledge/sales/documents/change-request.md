# 확정 주문 변경 요청

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

고객이 주문서 확정 뒤 수량이나 구성 변경을 요청하면 영업팀이 변경 내용을 기록하고 운영팀과 브랜드팀에 가능 여부를 확인합니다. 이미 진행한 공정에 따라 비용과 일정이 바뀔 수 있습니다. 새 확인 전에는 원래 납기를 유지한다고 안내하지 않습니다. 변경 요청에는 주문 번호, 바꿀 항목과 원하는 적용 시점을 포함합니다. 가능 여부를 회신한 뒤 고객이 확인한 변경본을 기준으로 관련 팀에 전달하며, 확인 전 요청 내용과 확정된 변경 내용을 구분해 남깁니다.
