# 견적에 포함할 제작·배송 범위

영업팀 · FAQ · v1 · 검색 사용

## 업무 지식

영업 견적에는 선택 구성품, 포장 방식, 로고 적용 위치, 개별 배송 건수와 도서·산간 여부를 구분해 적습니다. 같은 신입사원 선물 세트 수량이라도 포장과 배송지가 다르면 금액이 달라지므로 고정 단가를 추정해 안내하지 않습니다. 확정 견적서는 고객 담당자가 확인합니다. 초안에는 미확정 옵션을 표시하고 본주문에 반영할 항목을 고객과 확인합니다. 여러 고객에게 보낸 이전 견적의 총액을 이번 주문에 복사하지 않으며, 개별 배송과 일괄 배송을 비교할 때도 실제 발송 범위를 먼저 맞춥니다.
