# 온라인 행사 참가자 선물 주문 상담

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

온라인 세미나나 사내 원격 행사 선물은 참가 신청자 수와 실제 발송 수량을 나누어 확인합니다. 참가 등록만 했는지, 참석을 마쳤는지에 따라 발송 대상이 달라질 수 있으므로 고객이 대상 확정 기준을 정하도록 요청합니다. 영업팀은 행사일, 희망 수령 시점, 로고 사용 여부와 배송 방식을 주문 상담표에 남깁니다. 방송 접속 안내나 참석 확인 운영은 키트 제작 범위에 포함하지 않습니다. 참가자 명단 확정이 늦어지면 운영팀에 일정 영향을 확인한 뒤 고객에게 회신합니다.
