# 고객 불만 접수와 사실 확인 회신 분리

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

고객이 구성 누락이나 기대와 다른 인쇄를 알리면 영업팀은 주문 번호, 문제 항목, 영향 수량과 고객 요청을 먼저 기록합니다. 고객의 설명과 모아기프트가 확인한 사실을 나누고 운영·브랜드 중 확인할 팀을 지정합니다. 최초 회신은 접수 사실과 다음 확인 항목을 안내하는 것이며 원인이나 보완 방식을 미리 확정하는 답변이 아닙니다. 여러 채널로 같은 문의가 오면 한 건의 기록으로 연결합니다. 담당 팀의 확인 뒤 합의한 조치와 남은 질문을 고객에게 한 번에 정리해 전달합니다.
