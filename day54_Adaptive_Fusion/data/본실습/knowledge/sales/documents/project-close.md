# 주문 종료 뒤 고객 공유 요약

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

출고와 수령 확인이 끝난 주문은 영업팀이 고객에게 최종 구성, 실제 전달 수량, 처리 중인 문의를 간단히 요약합니다. 일부 물품에 문의가 남아 있으면 전체 처리가 완료됐다고 적지 않습니다. 종료 요약은 그 주문의 사실 기록이며 다음 주문의 가격·일정을 약속하는 문서가 아닙니다. 고객의 재주문 의향이나 후기 사용 가능 여부는 별도로 확인합니다. 운영팀의 출고 기록과 고객 담당자의 확인 내용을 대조하고 다른 주문의 결과를 복사해 붙이지 않습니다.
