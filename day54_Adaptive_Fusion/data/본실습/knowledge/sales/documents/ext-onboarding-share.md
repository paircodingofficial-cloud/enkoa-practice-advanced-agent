# 신규 고객 담당자에게 전달할 주문 안내 묶음

영업팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

고객사의 담당자가 바뀌면 현재 견적, 확정 주문서, 승인 시안의 위치와 미확정 질문 목록을 안내 묶음으로 정리합니다. 완료된 업무와 고객의 다음 확인이 필요한 업무를 분리하고, 각 항목의 모아기프트 담당 팀을 적습니다. 실제 수령인 명단은 모든 문서에 반복 첨부하지 않고 지정된 전달 경로를 안내합니다. 신규 담당자가 내용을 읽었다는 회신과 변경 요청이 없다는 승인은 다른 기록입니다. 요청 창구가 바뀌었다고 기존 승인 내용을 자동 취소하지 않으며 변경사항을 별도로 확인합니다.
