# 고객 담당자 인수인계 회고 — 프로젝트 회고 기록

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 담당: 영업팀
- 자료 종류: 프로젝트회고
- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

영업 담당자 교체 뒤 이전 상담에서 합의한 배송 방식이 후속 담당자에게 충분히 전달되지 않은 사례를 돌아보는 상황이었다.

## 작업 내역

확정 문서에 있는 내용과 메신저의 희망 요청을 나누어 본다. 새 담당자가 무엇을 어디서 확인할지 연결할 수 있도록 미확정 항목과 확인 창구를 묶었다.

## 확인된 사항

최근 신입사원 선물 세트 프로젝트에서 영업 담당자 변경 뒤 고객의 배송 방식 요청이 누락됐습니다. 앞으로 상담 메모에 고객이 승인한 구성, 미확정 항목, 다음 확인 담당자를 나누어 남깁니다. 상담 메모만으로 생산 지시를 대신하지 않습니다. 새 담당자는 이전 메모를 읽은 뒤 확정 주문서와 승인 시안이 실제로 있는지 확인합니다. 메신저에 남은 희망 사항을 확정 조건으로 옮기지 않고, 서로 다른 내용이 있으면 원래 확인 담당자에게 물어봅니다. 회고의 조치는 기록 방식을 바꾼 것이며 주문 기준 자체를 바꾸지 않습니다.

## 후속 작업

기록 방식의 개선 내용을 다음 인수인계에 반영하고 실제 주문 조건은 현행 문서에서 확인한다.
