# 제안 미채택 고객의 상담 종료 기록 — 프로젝트 회고 기록

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 담당: 영업팀
- 자료 종류: 프로젝트회고
- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

제안한 구성이 주문으로 이어지지 않은 상담을 다음 영업 회의에서 돌아보는 상황이었다.

## 작업 내역

고객이 직접 설명한 이유와 영업팀의 추측을 나눴다. 경쟁사 관련 말은 확인 수준을 표시하고 종료 상담이 생산 전망에 섞이지 않도록 읽었다.

## 확인된 사항

견적을 제출했으나 주문으로 이어지지 않으면 고객이 알려 준 사유와 영업팀의 추정을 분리해 기록합니다. 가격, 일정, 구성 적합성, 내부 행사 취소 중 확인된 이유만 확정 항목에 넣습니다. 경쟁사의 단가나 계약 조건을 들었다면 출처와 확인 수준을 남기고 사실로 확대하지 않습니다. 후속 연락을 원하는 시점이 있으면 기록하고, 종료된 상담을 생산 예정 건수에 포함하지 않습니다. 회고에서는 미채택 이유별 개선안을 논의하되 개별 상담 기록을 수정해 결과를 좋게 보이게 하지 않습니다.

## 후속 작업

확인된 이유에 맞는 개선안을 논의하고 원래 상담 기록은 결과에 맞춰 고치지 않는다.
