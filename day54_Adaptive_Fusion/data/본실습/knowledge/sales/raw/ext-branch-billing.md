# 본사 계약과 지점별 요청 창구 구분 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

## 접수·논의 배경

본사가 계약을 맡지만 여러 지점 담당자가 서로 다른 구성이나 문구를 요청하는 상황이었다.

## 작업 내역

본사 승인 창구와 지점 요청자를 분리하고 요청표에서 확인 상태를 읽었다. 지점 수를 배송 건수로 자동 변환하지 않도록 수량표를 별도로 뒀다.

## 확인된 사항

여러 지점에 키트를 보내는 거래에서는 계약을 승인할 본사 담당자와 지점별 요청자를 먼저 구분합니다. 지점마다 다른 구성이나 문구를 요청하면 본사 승인 여부를 표시한 요청표로 모읍니다. 지점 수와 배송 건수는 다를 수 있으므로 수량표를 별도로 받습니다. 영업팀은 견적 수신처와 주문 승인 창구를 본사에 재확인하며, 지점의 메신저 요청만으로 계약 범위를 바꾸지 않습니다. 제작·배송 가능 여부가 확인되면 변경된 범위를 같은 표에서 고객과 대조합니다.

## 후속 작업

본사에 승인된 범위를 확인하고 제작·배송 가능 여부가 확인된 변경만 견적에 반영한다.
