# 주문 전 실물 샘플 요청 — 고객 문의 검토 기록

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

## 접수·논의 배경

처음 주문하는 고객이 사진으로는 제품 크기와 재질을 판단하기 어려워 먼저 실물을 볼 수 있는지 문의한다.

## 작업 내역

공용 실물 샘플의 목적과 고객 로고 본제품의 승인 절차를 분리한다. 샘플에서 무엇을 확인하려는지 적고 수령 장소와 이후 선택 변경을 연결해 읽었다.

## 확인된 사항

고객이 구성품의 크기나 재질을 확인하려면 영업팀에 공용 실물 샘플을 요청합니다. 공용 샘플에는 고객 로고가 없으며 배송 일정은 별도로 확인합니다. 샘플 수령과 본주문 접수는 서로 다른 절차입니다. 요청에는 확인하고 싶은 품목과 재질, 받을 장소를 적습니다. 샘플을 본 뒤 고객이 구성을 바꾸면 변경 내용을 새 주문서에 반영해야 합니다. 샘플 검토 결과와 로고 최종 시안 승인은 서로 다른 기록으로 남깁니다.

## 후속 작업

샘플 의견을 새 주문 상담에 옮기되 본제품 시안 승인으로 바꾸어 기록하지 않는다.
