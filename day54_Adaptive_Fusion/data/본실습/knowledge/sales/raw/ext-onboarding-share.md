# 신규 고객 담당자에게 전달할 주문 안내 묶음 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 자료 종류: 업무가이드
- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

고객사 담당자가 바뀌어 새로운 담당자가 현재 주문 상태와 자료 위치를 알고 싶어 하는 상황이었다.

## 작업 내역

견적·주문서·시안·남은 질문을 상태별로 묶었다. 단순히 자료를 읽었다는 회신과 변경 없는 승인을 구분하고 수령인 명단의 전달 경로를 별도로 안내한다.

## 확인된 사항

고객사의 담당자가 바뀌면 현재 견적, 확정 주문서, 승인 시안의 위치와 미확정 질문 목록을 안내 묶음으로 정리합니다. 완료된 업무와 고객의 다음 확인이 필요한 업무를 분리하고, 각 항목의 모아기프트 담당 팀을 적습니다. 실제 수령인 명단은 모든 문서에 반복 첨부하지 않고 지정된 전달 경로를 안내합니다. 신규 담당자가 내용을 읽었다는 회신과 변경 요청이 없다는 승인은 다른 기록입니다. 요청 창구가 바뀌었다고 기존 승인 내용을 자동 취소하지 않으며 변경사항을 별도로 확인합니다.

## 후속 작업

새 창구의 변경 요청 여부를 확인하고 기존 승인 기록과 연결해 관리한다.
