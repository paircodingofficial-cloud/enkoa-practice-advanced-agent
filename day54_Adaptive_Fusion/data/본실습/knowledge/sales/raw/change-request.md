# 확정 주문 변경 요청 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 담당: 영업팀
- 자료 종류: 업무가이드
- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

고객이 주문서를 확정한 뒤 구성품이나 수량을 바꾸고 싶다고 연락하는 상황이었다.

## 작업 내역

요청한 내용과 실제로 반영 가능한 변경을 별도 상태로 둔다. 이미 진행 중인 작업이 있는지 운영·브랜드팀에 확인할 부분을 나누고 기존 일정과 연결했다.

## 확인된 사항

고객이 주문서 확정 뒤 수량이나 구성 변경을 요청하면 영업팀이 변경 내용을 기록하고 운영팀과 브랜드팀에 가능 여부를 확인합니다. 이미 진행한 공정에 따라 비용과 일정이 바뀔 수 있습니다. 새 확인 전에는 원래 납기를 유지한다고 안내하지 않습니다. 변경 요청에는 주문 번호, 바꿀 항목과 원하는 적용 시점을 포함합니다. 가능 여부를 회신한 뒤 고객이 확인한 변경본을 기준으로 관련 팀에 전달하며, 확인 전 요청 내용과 확정된 변경 내용을 구분해 남깁니다.

## 후속 작업

변경 가능 범위가 확인되면 고객 승인본과 팀 전달본이 같은 내용이 되도록 갱신한다.
