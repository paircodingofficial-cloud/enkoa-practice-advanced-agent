# 견적 상담 중 재고 확보 요청의 상태 안내 — 고객 문의 검토 기록

## 접수·논의 배경

견적을 검토 중인 고객이 아직 주문은 못 정했지만 상품 물량을 확보해 달라고 문의하는 상황이었다.

## 작업 내역

요청 접수·운영 검토·확보 확인을 서로 다른 상태로 적었다. 재고 회신과 생산 조건의 충족 여부를 연결하되 같은 완료 상태로 취급하지 않았다.

## 확인된 사항

고객이 견적 검토 중 상품을 확보해 달라고 요청하면 품목, 예상 수량, 주문 결정 예정 시점을 운영팀에 전달합니다. 영업 상담 기록에는 요청 접수, 운영 검토, 확보 확인을 서로 다른 상태로 남깁니다. 이 공유 문서에는 현재 재고와 확보 가능 수량이 없으므로 상담 단계에서 물량을 보장하지 않습니다. 운영팀 회신이 오면 유효 조건과 아직 미확정인 부분을 고객에게 그대로 안내합니다. 재고 확보 회신이 있더라도 주문서 확정·입금·시안 승인 등 제작 조건은 별도로 충족해야 합니다.

## 후속 작업

운영팀이 확인한 유효 조건과 미확정 사항을 받아 고객에게 안내한다.
