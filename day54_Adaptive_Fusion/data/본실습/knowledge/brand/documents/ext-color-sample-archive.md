# 재질별 인쇄 색상 검토 샘플 기록

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

색상 검토 샘플은 사용한 재질, 인쇄 방식, 로고 원본과 확인 조건을 함께 기록합니다. 종이에 나온 색상과 플라스틱 표면의 색상을 같은 기준으로 단정하지 않습니다. 이전 샘플은 새 주문을 검토할 때 참고할 수 있지만 재질이나 공급 품목이 바뀌었다면 재확인 필요성을 표시합니다. 고객이 확인한 샘플과 내부 비교용 샘플을 분리해 보관합니다. 브랜드팀은 색상 차이를 설명할 때 실제 확인 범위를 말하고 모든 제품에서 동일한 결과가 나온다는 보장으로 확대하지 않습니다.
