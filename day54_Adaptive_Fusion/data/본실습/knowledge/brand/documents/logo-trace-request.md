# 작은 로고 이미지를 원본처럼 그려 달라는 요청

브랜드팀 · FAQ · v1 · 검색 사용

## 업무 지식

고객이 작은 PNG 이미지만 보내면 브랜드팀은 먼저 원본을 받을 수 있는지 확인합니다. 파일 크기를 늘리는 것만으로 벡터 원본의 선명도가 생기지는 않습니다. 로고를 다시 그리는 작업은 기본 인쇄 검토와 별도 범위이므로 자동으로 진행하거나 완료 시점을 약속하지 않습니다. 필요하면 별도 작업 가능 여부와 고객 확인 절차를 안내합니다. 현재 제출 파일 기준은 logo-files이며, 참고용 이미지의 존재와 인쇄 가능한 원본의 준비 상태를 구분합니다.
