# 고객 로고 검토와 최종 시안 승인

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

브랜드팀은 필요한 로고 원본·색상·적용 제품·인쇄 위치가 모두 접수되면 2영업일 이내에 인쇄 가능 여부와 확인용 시안을 회신합니다. 영업일은 토요일·일요일·공휴일을 제외합니다. 2영업일은 브랜드 검토 기간이며 고객의 수정·승인 대기 시간은 포함하지 않습니다. 고객이 로고 크기·위치·색상과 문구를 확인해 최종 시안을 승인해야 제작 조건이 충족됩니다. 자료 보완이나 수정이 있으면 새 검토 일정을 안내합니다.
