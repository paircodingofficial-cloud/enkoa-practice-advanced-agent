# 화면 색상과 인쇄 색상 안내

브랜드팀 · FAQ · v1 · 검색 사용

## 업무 지식

고객에게 화면의 밝기와 인쇄 재질 때문에 로고 색상이 다르게 보일 수 있다고 설명합니다. 정확한 색상 요구는 지정 색상 정보로 받고 제작 가능 여부를 확인합니다. 화면 이미지가 같다는 이유로 모든 재질에서 동일한 결과를 보장하지 않습니다. 시안에는 고객이 확인한 색상 이름이나 코드를 기록해 말로 설명한 색과 구분합니다. 고객이 서로 다른 화면에서 본 결과가 다르다고 하면 파일 버전과 적용 제품을 먼저 대조합니다. 색상 보완 요청이 나오면 수정본의 승인 여부를 다시 확인해 운영팀에 전달합니다.
