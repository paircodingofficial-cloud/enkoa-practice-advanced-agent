# 인쇄 원본 접수 안내 변경 이력

브랜드팀 · 변경이력 · v1 · 검색 사용

## 업무 지식

2026년 9월 브랜드팀은 작은 이미지 파일만 받은 뒤 발생하는 원본 재요청을 줄이기 위해 고객 로고 접수 안내를 정리했습니다. 현재 안내는 brand:logo-files의 AI·SVG 원본과 색상·제품·위치 확인 기준을 따릅니다. 예전 logo-files-v1은 접수 방식이 달랐던 이유를 설명하는 기록이며 현재 파일 기준이 아닙니다. 이 변경은 모든 이미지를 벡터로 바꾸라는 일반 디자인 규칙이 아니라 가상 모아기프트의 고객 로고 인쇄 업무에 적용하는 기준입니다.
