# 제품 합성 이미지의 사용 범위

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

고객 로고를 제품 사진 위에 합성한 목업은 인쇄 위치와 전체 분위기를 확인하는 자료입니다. 실제 재질, 조명, 굴곡과 인쇄 공정을 모두 재현한 사진은 아닙니다. 고객이 목업의 색상이나 크기를 질문하면 합성 이미지와 실제 인쇄 조건을 구분해 설명합니다. 목업을 최종 제품 사진처럼 외부에 공개하지 않으며 공개가 필요하면 고객과 용도를 확인합니다. 인쇄용 파일의 준비 상태와 최종 승인 여부는 별도 작업 기록에서 확인합니다.
