# 소개 자료용 사진·일러스트의 출처 관리

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

브랜드팀이 소개 자료에 쓰는 사진과 일러스트는 원본 출처, 제공자, 사용 가능한 범위와 확인 기록을 연결합니다. 검색으로 발견한 이미지나 고객 메시지에 첨부된 사진을 자유롭게 공개할 수 있는 자료로 취급하지 않습니다. 크기를 자르거나 색상을 바꿔도 원래 사용 조건이 사라지는 것은 아니므로 편집본에도 원본 기록을 유지합니다. 고객 제품 사진은 별도 공개 확인을 받습니다. 사용 여부가 불명확한 자료는 공개 원고에 넣지 않고 확인할 담당자와 대체 후보를 기록합니다.
