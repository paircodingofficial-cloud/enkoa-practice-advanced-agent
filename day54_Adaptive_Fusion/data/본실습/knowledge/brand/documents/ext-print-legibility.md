# 안내 카드의 정보 순서와 읽기 쉬운 배치

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

안내 카드는 고객이 먼저 알아야 할 사용 목적, 확인할 행동과 문의 창구 순으로 정보를 배치합니다. 작은 글자를 늘려 모든 내용을 한 면에 넣기보다 중요도에 따라 내용을 정리하고 고객과 생략 가능 범위를 확인합니다. 배경과 글자의 대비, 줄바꿈과 여백은 실제 출력 크기에서 점검합니다. 색상만으로 서로 다른 주의사항을 구분하지 않고 문구나 기호를 함께 사용합니다. 브랜드팀은 보기 좋다는 내부 판단뿐 아니라 필수 조건이 읽히고 잘리지 않는지 승인본에서 확인합니다.
