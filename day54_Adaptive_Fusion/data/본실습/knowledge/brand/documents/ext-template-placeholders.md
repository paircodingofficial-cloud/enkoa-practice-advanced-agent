# 반복 사용하는 제안서 서식의 예시 문구 제거

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

제안서 서식에는 고객사명, 수량, 적용 제품과 일정 같은 바꿀 항목을 표시합니다. 새 고객에게 보내기 전에 예시 로고, 이전 고객 이름과 임시 금액이 남아 있지 않은지 확인합니다. 이미지에 들어간 글자는 본문 검색으로 찾기 어려우므로 실제 페이지도 읽어야 합니다. 서식의 기본 문구는 현재 상품 조건과 대조하고 담당 팀 확인이 필요한 항목을 자동 확정된 내용처럼 남기지 않습니다. 브랜드팀은 공개용 예시 파일과 실제 고객 작업본을 구분해 다른 고객 자료가 재사용되지 않게 합니다.
