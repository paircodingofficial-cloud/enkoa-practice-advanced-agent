# 납품 사례의 성과 숫자를 확인하는 원고표

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

사례 원고에서 주문 수량, 실제 배송 수량, 설문 응답자 수를 서로 다른 항목으로 기록합니다. 키트가 배송됐다는 사실만으로 직원 만족도가 높아졌다고 결론 내리지 않습니다. 고객이 제공한 성과 수치는 집계 범위와 공개 가능 여부를 확인하고, 일부 응답의 의견을 전체 직원의 평가로 확대하지 않습니다. 수치를 쓰기 어렵다면 확인 가능한 제작 과정이나 문제 해결 내용을 중심으로 설명합니다. 브랜드팀은 최종 문장 옆에 확인 자료를 연결해 수정 요청이 오면 해당 근거를 찾을 수 있게 합니다.
