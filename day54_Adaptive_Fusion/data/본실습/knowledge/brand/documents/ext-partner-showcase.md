# 협력사와 공동 공개하는 제작 사례 원고

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

협력사와 제작 사례를 함께 소개할 때는 각 회사의 역할, 공개 가능한 공정 정보와 사용할 사진을 먼저 정리합니다. 공급사가 보낸 공정 사진에 고객 로고가 보이면 고객의 공개 확인도 필요하므로 공급사 동의만으로 게시하지 않습니다. 기획, 생산, 포장 중 누가 무엇을 맡았는지 확인한 범위에서 설명하고 모든 작업을 한 회사가 수행한 것처럼 표현하지 않습니다. 브랜드팀은 양측 검토 의견과 최종 원고를 연결해 보관하고 공개 채널이 추가되면 기존 승인 범위를 다시 확인합니다.
