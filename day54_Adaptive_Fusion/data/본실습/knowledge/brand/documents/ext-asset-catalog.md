# 브랜드 자산 목록의 용도와 사용 상태

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

브랜드팀 자산 목록에는 파일명, 소유 주체, 사용 가능한 채널, 승인 상태와 원본 위치를 기록합니다. 고객이 제작 검토를 위해 보낸 자료와 공개 홍보에 쓸 수 있는 자료를 구분해야 합니다. 영업 제안서에서 찾기 쉽도록 상품군이나 사용 장면을 태그로 붙일 수 있지만 태그가 사용 승인을 대신하지는 않습니다. 오래된 파일은 삭제 여부를 임의로 결정하지 않고 현재 사용본과 참고 보관본으로 나눕니다. 새 담당자는 목록의 미리보기만 보고 인쇄하지 말고 승인된 원본과 적용 조건을 확인합니다.
