# 여러 로고를 함께 넣는 시안

브랜드팀 · FAQ · v1 · 검색 사용

## 업무 지식

고객사와 협력사 로고를 함께 표시하려면 각 원본, 배치 순서, 상대 크기와 사용 조건을 받습니다. 브랜드팀이 확인용 시안에서 충돌 여부를 점검하고 고객 담당자가 최종 배치를 승인합니다. 기존 단일 로고 시안에 파일만 추가해 제작하지 않습니다. 고객에게는 실제 사용할 로고 변형본을 지정해 달라고 요청합니다. 원본이 여러 폴더에 나뉘어 있어도 파일이 있다는 사실만으로 최신본을 알 수는 없습니다. 브랜드팀은 선택한 파일과 시안 버전을 연결해 운영팀이 이전 로고를 사용하지 않도록 전달합니다.
