# 고객 브랜드 가이드가 함께 온 경우

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

고객이 브랜드 가이드를 주면 브랜드팀은 로고 주변 여백, 최소 사용 크기, 허용 색상과 금지 배치를 인쇄 대상에 적용할 수 있는지 확인합니다. 문서에 여러 로고 변형이 있어도 고객이 원하는 적용본을 임의로 고르지 않습니다. 작은 제품에서 가이드 조건을 만족하기 어려우면 대안을 제안하고 고객의 확인을 받습니다. 브랜드 가이드가 접수됐다는 사실은 개별 제품 시안의 승인을 뜻하지 않으며 실제 인쇄 위치와 크기는 최종 시안에서 다시 확인합니다.
