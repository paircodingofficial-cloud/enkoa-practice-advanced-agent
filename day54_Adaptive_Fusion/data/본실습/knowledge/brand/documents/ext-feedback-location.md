# 시안 수정 의견을 위치별로 받는 방법

브랜드팀 · 업무가이드 · v1 · 검색 사용

## 업무 지식

여러 사람이 시안을 검토하면 페이지나 면, 수정할 요소, 원하는 변경과 요청자를 함께 기록합니다. '좀 더 크게' 같은 의견은 어느 로고나 문구를 말하는지 확인한 뒤 작업합니다. 서로 반대되는 의견은 브랜드팀이 임의로 골라 적용하지 않고 고객의 최종 확인 창구에 묶어서 질문합니다. 반영 여부와 보류 이유를 남겨 수정본에서 무엇이 달라졌는지 보여 줍니다. 수정 의견이 모두 반영됐다는 내부 점검과 고객이 최종본을 승인했다는 기록은 구분해 관리합니다.
