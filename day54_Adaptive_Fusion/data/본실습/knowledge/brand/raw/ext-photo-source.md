# 소개 자료용 사진·일러스트의 출처 관리 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 담당: 브랜드팀
- 자료 종류: 업무가이드
- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

제품 소개 원고에 넣을 사진을 검색 결과와 고객 첨부 이미지에서 함께 고르는 상황이었다.

## 작업 내역

출처·제공자·확인 범위를 원본과 편집본에 연결했다. 편집 여부와 공개 사용 가능 여부를 같은 기준으로 보지 않는다.

## 확인된 사항

브랜드팀이 소개 자료에 쓰는 사진과 일러스트는 원본 출처, 제공자, 사용 가능한 범위와 확인 기록을 연결합니다. 검색으로 발견한 이미지나 고객 메시지에 첨부된 사진을 자유롭게 공개할 수 있는 자료로 취급하지 않습니다. 크기를 자르거나 색상을 바꿔도 원래 사용 조건이 사라지는 것은 아니므로 편집본에도 원본 기록을 유지합니다. 고객 제품 사진은 별도 공개 확인을 받습니다. 사용 여부가 불명확한 자료는 공개 원고에 넣지 않고 확인할 담당자와 대체 후보를 기록합니다.

## 후속 작업

불명확한 이미지의 확인 담당과 대체 후보를 정리하고 공개 원고에서는 제외한다.
