# 시안 수정 의견을 위치별로 받는 방법 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 담당: 브랜드팀
- 자료 종류: 업무가이드
- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

여러 고객 담당자가 시안에 더 크게 또는 위치를 바꿔 달라는 의견을 남겨 대상이 모호한 상황이었다.

## 작업 내역

페이지·면·수정 요소·요청자를 함께 적었다. 서로 반대되는 의견과 내부 반영 완료를 고객의 최종 승인과 구분했다.

## 확인된 사항

여러 사람이 시안을 검토하면 페이지나 면, 수정할 요소, 원하는 변경과 요청자를 함께 기록합니다. '좀 더 크게' 같은 의견은 어느 로고나 문구를 말하는지 확인한 뒤 작업합니다. 서로 반대되는 의견은 브랜드팀이 임의로 골라 적용하지 않고 고객의 최종 확인 창구에 묶어서 질문합니다. 반영 여부와 보류 이유를 남겨 수정본에서 무엇이 달라졌는지 보여 줍니다. 수정 의견이 모두 반영됐다는 내부 점검과 고객이 최종본을 승인했다는 기록은 구분해 관리합니다.

## 후속 작업

확인 창구에 충돌 의견을 묶어 질문하고 수정본의 반영·보류 상태를 남긴다.
