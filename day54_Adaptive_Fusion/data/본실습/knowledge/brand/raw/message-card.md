# 환영 메시지 카드 원고 — 업무 검토 메모

## 접수·논의 배경

선물 세트에 넣을 환영 카드의 문구와 보낸 사람 표기가 아직 여러 버전으로 나뉘어 있는 상황이었다.

## 작업 내역

제안 문장과 고객 확정 문장을 나누고 이름·직함·줄바꿈을 대조할 항목을 적었다. 대상별 문구가 다른 경우 적용 수량과 작업 범위를 함께 읽었다.

## 확인된 사항

신입사원 선물 세트에 넣을 메시지 카드는 최종 문구와 보낸 사람 표기를 받습니다. 고객 담당자가 이름·직함·맞춤법을 확인한 문구를 전달하고 시안에서 줄바꿈과 잘림을 확인합니다. 메시지 카드 추가 여부는 확정 구성표에 남깁니다. 인사말 제안과 고객이 확정한 문구를 같은 상태로 보관하지 않습니다. 고객이 여러 대상에게 다른 문구를 넣길 원하면 각각의 문구와 적용 수량을 확인해 작업 범위를 정리합니다. 담당자는 최종 원고와 승인 시안의 문장이 같은지 확인한 뒤 제작용 파일로 넘깁니다.

## 후속 작업

최종 원고와 승인 시안의 내용이 같은지 확인한 뒤 제작 파일로 연결한다.
