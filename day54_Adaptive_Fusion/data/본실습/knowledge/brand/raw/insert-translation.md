# 외국어 메시지 카드 원고 확인 — 고객 문의 검토 기록

## 접수·논의 배경

고객이 외국어 환영 카드를 요청하면서 번역 초안과 이름 표기를 함께 보내는 상황이었다.

## 작업 내역

문장 정확성을 확인할 고객 담당자와 브랜드팀의 배치 검토 역할을 나눴다. 자동 번역 초안과 최종 인쇄 원고를 구분했다.

## 확인된 사항

고객이 외국어 메시지 카드를 요청하면 최종 원고와 줄바꿈을 확인할 담당자를 지정해 받습니다. 브랜드팀은 배치와 잘림을 점검하지만 외국어 문장의 정확성을 임의로 보증하지 않습니다. 고객 승인 전 자동 번역 결과를 최종 인쇄 문구로 사용하지 않습니다. 이름·직함·고유명사는 고객이 확인한 표기를 그대로 쓰고 변경 요청은 시안 버전과 연결해 기록합니다. 번역이나 별도 교정이 필요한 경우 기본 메시지 카드 작업과 구분해 상담합니다.

## 후속 작업

고객 확정 원고를 받아 표기·배치를 대조하고 별도 교정 요청은 범위를 확인한다.
