# 제품 소개 이미지의 설명 문구 작성 — 업무 검토 메모

- 기준 상태: 현행 기준

## 접수·논의 배경

제품 이미지를 보지 못해도 핵심 차이를 이해할 수 있도록 설명 문구를 붙이는 상황이었다.

## 작업 내역

사진에 보이는 포장·로고와 사진으로는 알 수 없는 성능·효능을 구분했다. 이미지의 정보 역할과 본문에서 다시 읽어야 할 조건을 나눴다.

## 확인된 사항

이미지 설명은 사진에 있는 제품과 중요한 차이를 짧게 전달하도록 작성합니다. 로고가 보이는지, 어떤 포장 방식인지처럼 확인 가능한 내용을 쓰고 사진으로 알 수 없는 재질의 효능이나 품질을 추정하지 않습니다. 이미지 안의 글자가 문의에 필요한 정보라면 본문에서도 읽을 수 있게 제공합니다. 장식용 사진과 주문 조건을 설명하는 사진은 역할을 구분합니다. 브랜드팀은 설명 문구를 제품 담당 정보와 대조하고, 사진과 문구가 서로 다른 버전의 상품을 가리키면 함께 수정합니다.

## 후속 작업

상품 담당 자료와 문구를 대조하고 이미지와 설명의 버전이 다르면 함께 수정한다.
