## 접수·논의 배경

제안서에서 잘 보이는 글꼴을 인쇄물과 외부 전달 파일에도 사용할 수 있는지 묻는 상황이었다.

## 작업 내역

화면에서 열리는 상태와 사용 조건의 확인을 구분했다. 고객 지정 글꼴도 필요한 자료가 있는지 읽고 외부 전달 방법을 별도로 확인했다.

## 확인된 사항

제안서와 인쇄물을 만들 때 사용한 글꼴의 이름과 사용 조건을 확인한 자료의 위치를 남깁니다. 화면에서 열 수 있다는 사실만으로 고객 배포나 상업 인쇄에 사용할 수 있다고 판단하지 않습니다. 고객이 지정한 글꼴도 필요한 파일과 확인 정보를 요청하고 부족하면 대체안을 협의합니다. 제작 외부 전달이 필요한 경우 글꼴 파일을 무조건 함께 보내지 않고 허용된 방법을 확인합니다. 이 자료는 사용 조건을 확인하는 업무 절차이며 특정 글꼴의 권리 범위나 법률 판단을 제공하지 않습니다.

## 후속 작업

조건 확인 자료를 연결하고 부족하면 고객과 대체안을 협의한다.
