# 제품 합성 이미지의 사용 범위 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

## 접수·논의 배경

고객이 제품 사진 위에 로고를 합성한 이미지를 실제 제작 사진처럼 이해할 수 있는 상황이었다.

## 작업 내역

목업으로 확인하는 위치·분위기와 실제 재질·빛·굴곡의 차이를 적었다. 인쇄 준비 상태와 공개 사용 목적을 다른 검토 항목으로 남겼다.

## 확인된 사항

고객 로고를 제품 사진 위에 합성한 목업은 인쇄 위치와 전체 분위기를 확인하는 자료입니다. 실제 재질, 조명, 굴곡과 인쇄 공정을 모두 재현한 사진은 아닙니다. 고객이 목업의 색상이나 크기를 질문하면 합성 이미지와 실제 인쇄 조건을 구분해 설명합니다. 목업을 최종 제품 사진처럼 외부에 공개하지 않으며 공개가 필요하면 고객과 용도를 확인합니다. 인쇄용 파일의 준비 상태와 최종 승인 여부는 별도 작업 기록에서 확인합니다.

## 후속 작업

고객에게 목업의 확인 범위를 설명하고 공개 요청은 별도로 확인한다.
