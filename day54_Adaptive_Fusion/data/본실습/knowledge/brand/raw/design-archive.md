# 승인 시안 파일 보관 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

- 기준 버전: v1
- 기준 상태: 현행 기준

## 접수·논의 배경

같은 주문 폴더에 수정 중 로고 파일과 승인본이 섞여 있어 운영팀에 무엇을 전달할지 정리하는 상황이었다.

## 작업 내역

파일명만 보지 않고 주문 번호·승인 기록·버전을 함께 읽었다. 과거 주문 파일의 재사용 가능성과 새 주문의 승인 여부를 다른 항목으로 뒀다.

## 확인된 사항

최종 승인 시안은 주문 번호와 승인 날짜로 구분하고 수정 중 파일과 분리해 보관합니다. 운영팀에는 승인된 버전만 전달합니다. 고객의 새 요청은 기존 파일을 덮어쓰지 않고 변경 이력에 남깁니다. 파일 이름만으로 승인 여부가 분명하지 않으면 고객 승인 기록을 확인합니다. 과거 주문의 승인본을 찾았더라도 새 제품의 인쇄 영역이나 로고 내용이 바뀌었는지 다시 검토합니다. 보관된 자료의 재사용과 새 주문의 승인을 같은 의미로 취급하지 않습니다.

## 후속 작업

고객이 확인한 파일을 식별해 전달하고 변경 요청은 별도 이력으로 연결한다.
