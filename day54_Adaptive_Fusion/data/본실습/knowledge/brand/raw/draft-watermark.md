# 검토 중 시안과 승인본의 파일 표시 — 업무 검토 메모

> 수업용 가상 업무기록 · 2026-10-02 정리. `policy_updated`는 기준자료의 버전 날짜입니다.

## 접수·논의 배경

수정한 시안을 고객에게 보냈지만 최종 승인이 아직 확인되지 않아 내부 파일 표시를 정리하는 상황이었다.

## 작업 내역

검토용 파일·최종 승인본·운영 전달본을 서로 다른 상태로 읽었다. 수정 반영을 끝낸 것과 고객이 승인한 것을 구분하는 표시를 검토했다.

## 확인된 사항

브랜드팀이 고객에게 보내는 검토 중 시안에는 검토용 표시와 파일 버전을 남깁니다. 고객 의견을 반영한 파일이라고 해서 자동으로 최종 승인본이 되는 것은 아닙니다. 최종본은 고객이 확인한 로고·색상·크기·문구와 승인 기록을 연결해 보관합니다. 운영팀에는 그 승인본을 전달하고 구버전이나 수정 중 파일을 같은 이름으로 덮어쓰지 않습니다. 시안의 접수·검토 기간은 proof-approval을 따르며 파일 표시 규칙 자체가 승인 절차를 대신하지 않습니다.

## 후속 작업

승인 기록과 파일 버전을 연결해 운영팀에는 확인된 본만 전달한다.
