# 과제 자료: 루나 팬 대화 챗봇

과제 01·02가 함께 쓰는 자료입니다. 모든 파일은 직접 고치지 않습니다.

| 파일 | 개수 | 내용 |
|---|---:|---|
| `docs.jsonl` | 14편 | 루나 공식 안내 문서(프로필, 음반, 팬미팅 공지·환불·입장, 굿즈, 응원봉, 팬클럽, 방송, 팬레터, 앱 계정, 팬아트, 안전 공지). 필드 `doc_id`, `title`, `text` |
| `golden.jsonl` | 12건 | 팬 질문 골든셋(정답셋). 단일 사실 5, 예외·조건 2, 여러 문서 결합 3, 자료에 없는 질문 2. `smoke`가 참인 6건은 빠른 점검용 |
| `chroma/` | 14개 벡터 | 문서 벡터(text-embedding-3-large, 768차원, 컬렉션 `luna_guides`). 학생은 질문만 임베딩합니다 |
| `chroma_manifest.json` | - | 문서 벡터의 컬렉션 이름, 모델, 차원, 개수, 원문 지문 |
| `sources.json` | - | 자료의 출처(루나 설정), 문서 해시, 골든셋 정답 답변의 근거 문장 |

## 가상 설정

- 루나와 루미너스 엔터테인먼트, 팬미팅, 굿즈, 일정, 금액은 모두 수업용 가상 자료입니다.
- 루나 설정은 지난 단원(LLM 판사)의 루나 설정을 잇고, 공식 안내 문서 6편은 다음 단원(가드레일) 과제의 루나 문서와 같은 글입니다.
- 자료에 없는 질문 두 개(VIP 입장 시각, 티켓 가격)는 어느 문서에도 답이 없습니다.

## 골든셋 필드

| 필드 | 설명 |
|---|---|
| `case_id` | 사례 ID(`fan-01`~`fan-12`) |
| `input` | 팬 질문 |
| `expected_output` | 정답 답변 문장(자료에 없는 질문은 확인할 수 없다는 안내 문장) |
| `context` | 정답 근거 문장 목록(자료에 없는 질문은 `["공식 안내에 이 질문에 대한 내용이 없음"]`) |
| `relevant_doc_ids` | 정답 근거 문장이 나온 문서의 `doc_id` 목록(자료에 없는 질문은 빈 목록) |
| `smoke` | 빠른 점검 6건에 들면 참 |
