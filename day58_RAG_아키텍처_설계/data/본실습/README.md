# day58 본실습 데이터: 국내 관광지 388곳

교안 3권(임베딩 모델 선택, 벡터 저장소 선택, 검색 전략과 아키텍처 종합 선정)이 함께 쓰는 검색 실습 자료입니다.

## 출처와 이용 조건

- 출처: 한국관광공사 TourAPI 국문 관광정보 서비스(KorService2, 공공데이터포털)
  - 쓴 오퍼레이션: `areaBasedList2`(목록), `detailCommon2`(개요), `detailIntro2`(이용 시간·쉬는 날·주차·문의), `detailInfo2`(입장료), `ldongCode2`(법정동 시도·시군구 이름), `lclsSystmCode2`(분류체계 이름)
- 이용 조건: 개요 글은 공공누리 제1유형(출처표시)에 따라 출처를 밝히고 씁니다. 사진은 쓰지 않았습니다.
- 수집일: 2026-10-08
- 개요 글은 HTML 태그, `<br>`, HTML 엔티티를 지우고 공백을 하나로 모았습니다. 문자열은 모두 NFC 정규화했습니다.
- 시도 이름은 짧은 이름으로 적었습니다(예: 서울특별시는 `서울`, 강원특별자치도는 `강원`). TourAPI 법정동 코드에 `전남광주통합특별시` 로 나오는 지역(옛 전라남도와 광주광역시)은 `전남광주` 입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `spots.jsonl` | 관광지 문서 388건. 한 줄에 JSON 하나 |
| `spot_info.csv` | 관광지별 운영 정보 388행(SQL JOIN 실습용) |
| `spots_nearby.csv` | 10km 안 가까운 관광지 관계 1476행 |
| `questions.json` | 검색 평가용 질문 골드셋 75개 |
| `questions_meta.json` | 질문을 만든 방법과 검증 기록(학생 실습에는 필요 없음) |

### spots.jsonl

```json
{"doc_id": "spot_<contentid>", "title": "이름", "text": "정리한 개요 글",
 "metadata": {"contentid": "...", "sido": "서울", "sigungu": "종로구", "category": "역사관광/고궁",
              "addr": "주소", "mapx": 126.97, "mapy": 37.57, "modifiedtime": "YYYYMMDDhhmmss"}}
```

- `category` 는 TourAPI 분류체계의 `대분류/소분류` 입니다(예: `자연관광/해변·해수욕장`). 소분류 이름 안의 `, ` `/` `ㆍ` 는 `·` 로 바꿨습니다.
- `mapx` 는 경도, `mapy` 는 위도(WGS84)입니다.
- 본문 길이(글자): 최소 175, 중앙값 406, 최대 1462. 150자 미만인 곳은 뺐습니다.

### spot_info.csv

| 열 | 내용 |
|---|---|
| `doc_id` | `spots.jsonl` 의 doc_id |
| `usetime` | 이용 시간 |
| `restdate` | 쉬는 날 |
| `parking` | 주차 |
| `infocenter` | 문의 및 안내 |
| `usefee` | 입장료(반복정보의 입장료·이용요금 항목). 정보가 없으면 빈 칸 |
| `is_free` | `usefee` 가 '무료'만 말하면 1, 금액만 있으면 0, 둘 다 있거나 정보가 없으면 빈 칸(판단 보류) |

`is_free` 분포: 1이 219곳, 0이 48곳, 빈 칸이 121곳.

### spots_nearby.csv

`src_id`, `dst_id`, `distance_km`(하버사인 거리, 소수 둘째 자리). 관광지마다 10km 안에 있는 다른 관광지를 가까운 순서로 최대 5곳 남겼습니다. 이웃이 하나 이상 있는 관광지는 367곳입니다.

### questions.json

```json
{"question_id": "q001", "question": "...", "question_type": "묘사",
 "relevant_doc_ids": ["spot_..."], "filter": {"sido": "경북", "sigungu": "울릉군"}, "answer": 3, "note": "..."}
```

| 유형 | 개수 | 뜻 |
|---|---|---|
| 묘사 | 15 | 이름 없이 특징을 다른 말로 묘사한 질문 |
| 이름 | 15 | 본문에 나오는 드문 고유명사가 들어 있어 단어 일치가 중요한 질문 |
| 조건 | 15 | 지역 조건과 의미 조건이 함께 있는 질문. `filter` 를 같이 씁니다 |
| 관계 | 15 | 어떤 관광지 근처의 다른 관광지를 묻는 질문. 정답은 `spots_nearby.csv` 에서 계산 |
| 집계 | 15 | 개수나 1위를 묻는 질문. `answer` 에 계산값, `relevant_doc_ids` 에 해당 문서 전부 |

- `filter` 는 조건 질문에만 있습니다. 키는 `metadata` 의 `sido`, `sigungu` 입니다. 시군구 이름은 시도끼리 겹칠 수 있어서(예: 중구) 시군구 필터에는 시도를 함께 적었습니다.
- 묘사·이름·조건 질문은 모델이 초안을 쓰고, 후보 문서를 모델에게 다시 보여 주어 정답이 더 있는지 확인했습니다. 정답이 여럿이면 `relevant_doc_ids` 에 모두 넣었습니다.
  - 묘사: 후보는 BM25 상위 5, multilingual-e5-small 상위 5, 같은 분류 문서(두 순위를 합친 상위 5)입니다. 어느 한 검색 방식에 유리하지 않도록 둘을 함께 썼습니다.
  - 묘사 질문은 본문과 다른 낱말로 바꿔 말하게 했고, 코드로 두 가지를 막았습니다. 질문 명사 가운데 정답 문서(제목+본문)에도 나오는 명사의 비율이 0.40 이하여야 하고, 문서 세 곳 미만에만 나오는 세 글자 이상 명사는 질문에 쓸 수 없습니다.
  - 이름·조건: 후보는 BM25 상위 후보와 같은 분류 문서입니다(이름 질문은 핵심어가 들어간 문서, 작은 지역 조건 질문은 그 지역 문서 전부를 더했습니다).
- 유형마다 15개씩입니다. 어느 질문을 넣을지는 검색 결과를 보지 않고 정해진 규칙으로 골랐습니다.
