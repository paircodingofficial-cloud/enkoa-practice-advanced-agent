# 이서연

**지원 분야: AI Agent 개발 / 신입**

Python으로 데이터를 분석하고, 문서 검색과 지식 그래프를 결합한 AI 서비스를 만드는 데 관심이 있습니다. 교육 과정의 팀 프로젝트에서 데이터 전처리, 지식 추출, 검색 평가와 LangGraph 워크플로 구현을 맡았습니다. 답변과 함께 근거를 확인할 수 있는 서비스를 만드는 데 집중했습니다.

## 기술 역량

- **데이터 처리:** Python·pandas를 활용한 API 데이터 수집, 전처리, 분석·시각화, SQL·PostgreSQL 질의.
- **문서 검색과 답변:** LangChain, OpenAI API, 구조화된 출력, 임베딩·벡터 DB, 검색 품질 평가.
- **지식 그래프:** Neo4j·Cypher, 개체·관계 추출, 개체 정규화, 그래프와 벡터를 결합한 검색.
- **에이전트 개발:** LangGraph의 상태·분기·반복, 대화 저장, 사람 검토, 도구 호출과 멀티에이전트 구성.
- **품질 평가와 서비스 구성:** RAGAS·NeMo Guardrails, LoRA·QLoRA, vLLM·FastAPI, Streamlit·Docker·CI/CD, Git/GitHub.

## 교육

**LLM 지식 그래프 기반 신뢰형 GraphRAG 구축을 위한 머신러닝 엔지니어 양성 과정** · 960시간

Python 데이터 분석부터 지식 그래프, RAG·에이전트 개발, 모델 튜닝, 평가와 배포까지 학습했습니다.

## 프로젝트 경험

### 1. 기업 도메인 데이터 분석 대시보드 및 RAG 개발

기업 도메인 데이터를 분석하고, 분석 결과와 문서 검색을 한 화면에서 확인하는 서비스입니다.

- **주요 기능:** API 수집·전처리, 데이터 분석, 벡터 DB 검색, LangChain 기반 질의응답, Streamlit 대시보드.
- **담당 업무:** 수집 데이터의 결측값·중복을 정리하고, 검색 평가용 질문과 관련 문서를 정리했습니다. 검색 결과를 비교해 개선할 질문 유형을 확인했습니다.
- **사용 기술:** Python, pandas, LangChain, 벡터 DB, Streamlit.
- **결과물:** 데이터셋과 전처리 명세, 분석 리포트, 대시보드·RAG 통합 앱, 검색 품질 평가 결과.

### 2. 사내 기술 문서 개체 추출기

기술 문서의 개체와 관계를 추출해 Neo4j에 저장하고 질의응답에 활용하는 프로젝트입니다.

- **주요 기능:** LLM 기반 개체·관계 추출, 동일 개체 통합, 온톨로지 매핑, 지식 그래프 적재·조회.
- **담당 업무:** 개체·관계의 출력 스키마와 추출 프롬프트를 작성했습니다. 같은 개체의 표기를 정리하고 Neo4j 적재 결과를 Cypher로 확인했습니다.
- **사용 기술:** Python, LLM 구조화 출력, Neo4j, Cypher.
- **결과물:** 추출 코드·프롬프트, 그래프 스키마와 시각화, 추출 품질 리포트, 질의응답 데모.

### 3. 할루시네이션 방지 지식 검색 필터

검색 근거를 확인하고, 근거가 부족한 답변을 줄이기 위한 검색·검증 시스템입니다.

- **주요 기능:** 하이브리드 검색, 여러 관계를 따라가는 추론, 검색·추론·검증 에이전트, RAGAS 평가, NeMo Guardrails.
- **담당 업무:** 질문 유형에 따라 검색 경로를 고르는 LangGraph 흐름을 작성했습니다. 평가 질문으로 답변과 검색 근거를 대조하고 근거가 부족한 사례를 정리했습니다.
- **사용 기술:** LangGraph, 하이브리드 검색, RAGAS, NeMo Guardrails.
- **결과물:** 검색·추론 엔진, 품질 평가 리포트, 가드레일 명세, 에이전트 실행 기록.

### 4. 최종 프로젝트: 기업 기술 문서를 탐색하는 GraphRAG 에이전트

**주제:** 엔터프라이즈 지식 자산 최적화를 위한 지능형 GraphRAG 도메인 에이전트

기술 백서에서 지식을 추출하고, 문서와 관계를 함께 검색해 답하는 서비스입니다.

- **주요 기능:** 온톨로지 설계, Neo4j 지식 추출, 하이브리드 GraphRAG, LangGraph 멀티에이전트, 답변 평가·가드레일·서빙.
- **담당 업무:** 문서 검색과 관계 조회 결과를 답변 노드에 전달하는 흐름을 구성했습니다. 답변에 사용한 근거를 확인할 수 있도록 결과 형식을 정리하고 평가 사례를 문서화했습니다.
- **사용 기술:** LangGraph, LangChain, Neo4j, GraphRAG, FastAPI.
- **결과물:** 요구사항과 그래프 스키마, 데이터 적재 코드, GraphRAG·에이전트 엔진, 웹 앱, 성능 평가 보고서.
