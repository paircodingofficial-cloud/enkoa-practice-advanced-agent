# 김도윤

**지원 분야: AI Agent 개발 / 신입 준비**

동아리 행사 운영을 도우며 신청자 정보를 정리하고 운영팀과 현황을 공유했습니다. 반복되는 자료 정리와 문의 대응을 줄이는 AI 서비스를 개발하고 싶습니다.

## 활동 경험

### 동아리 행사 신청자 관리

- Excel로 신청자 명단을 정리하고 중복 신청을 확인했습니다.
- 신청 양식의 항목을 통일해 자료를 같은 형식으로 정리했습니다.
- 연락처가 빠진 신청 건은 담당자에게 확인을 요청했습니다.
- 운영팀에 주간 신청 현황을 공유했습니다.

## 사용 도구와 강점

- **자료 정리:** Excel 명단 관리, 중복 항목 확인, 입력 형식 통일.
- **협업:** 누락 정보 확인 요청과 주간 현황 공유.

## 활동 결과물

- 중복 신청을 확인할 수 있도록 정리한 신청자 명단.
- 항목을 통일한 신청 양식과 누락 정보 확인 목록.
- 운영팀에 공유한 주간 신청 현황.

## 현재 학습

현재 SQL 기초를 학습하고 있습니다. Python·LLM·RAG 프로젝트는 아직 진행하지 않았습니다.

## 지원 동기

명단을 정리하고 누락 정보를 확인하는 과정에서 반복 업무를 줄일 방법에 관심을 갖게 됐습니다. SQL과 Python을 익혀 자료를 처리하는 기초를 쌓고, 이후 문서 검색과 문의 대응을 돕는 AI Agent를 구현하고 싶습니다.
